# Multiclass Classification — Complete Beginner Notes

## 1. What Is Multiclass Classification?

First, remember:

- Binary = Two
- Multi = More than two

In Binary Classification, a model chooses between two possible classes.

In Multiclass Classification, a model chooses one class from three or more possible classes.

**Simple definition:**

Multiclass Classification is a supervised machine learning task in which a model predicts exactly one class from three or more possible classes.

## 2. Understand With a Simple Example

Imagine we want to build an AI model that recognizes animals in pictures.

The model has four possible categories:

1. Cat
2. Dog
3. Horse
4. Elephant

We give the model an animal picture.

The model examines the picture and predicts:

**Dog**

Why?

Because it believes the picture belongs to the Dog category.

This is Multiclass Classification.

## 3. Understand Input (X) and Output (Y)

Imagine we have a dataset containing animal information.

| Weight | Height | Animal |
|---:|---:|---|
| 4 kg | 25 cm | Cat |
| 25 kg | 60 cm | Dog |
| 400 kg | 150 cm | Horse |
| 3,000 kg | 300 cm | Elephant |
| 5 kg | 27 cm | Cat |
| 30 kg | 65 cm | Dog |

Here:

- Weight = Input feature
- Height = Input feature
- Animal = Target or label

The target contains four possible classes:

- Cat
- Dog
- Horse
- Elephant

The model learns patterns from the examples and predicts an animal category for new information.

Note: This is a simplified example, not a realistic animal recognition system.

## 4. How Does Multiclass Classification Work?

Let's understand step by step.

**Step 1: Provide training data**

We give the model many examples of animals with their correct labels.

**Step 2: The model learns**

It studies patterns in the input features.

**Step 3: Give new information**

We provide a new animal picture or its features.

**Step 4: The model predicts one class**

For example:

Dog.

The model chooses one category from the available classes.

## 5. How Does Probability Work in Multiclass Classification?

A classification model can estimate a probability for every possible class.

Imagine our model recognizes four animals.

Its predictions are:

| Class | Probability |
|---|---:|
| Cat | 10% |
| Dog | 70% |
| Horse | 15% |
| Elephant | 5% |

The model predicts Dog because it has the highest probability.

Another example:

| Class | Probability |
|---|---:|
| Cat | 60% |
| Dog | 20% |
| Horse | 15% |
| Elephant | 5% |

The prediction is Cat.

In a standard multiclass probability output, the probabilities across all classes add up to 100%.

Remember: A high predicted probability does not guarantee that the prediction is correct.

## 6. Binary vs Multiclass Classification

| Binary Classification | Multiclass Classification |
|---|---|
| Two possible classes | Three or more possible classes |
| Spam / Not Spam | Cat / Dog / Horse |
| Pass / Fail | Low / Medium / High |
| Fraud / Genuine | Sports / Politics / Business |
| Positive / Negative | 0 to 9 digit recognition |

The main difference is the number of possible classes.

## 8. Important Multiclass Classification Algorithms

Many classification algorithms can be used for multiclass problems.

### 8.1 Logistic Regression

Logistic Regression can be extended to multiclass classification.

Two common approaches are:

- One-vs-Rest (OvR)
- Multinomial Logistic Regression

### 8.2 Decision Tree Classifier

A Decision Tree uses a sequence of conditions to choose one class from multiple possibilities.

### 8.3 Random Forest Classifier

Random Forest combines predictions from multiple decision trees to produce a class prediction.

### 8.4 K-Nearest Neighbors (KNN)

KNN looks at nearby training examples and uses their class labels to predict the new example's class.

### 8.5 Support Vector Machine (SVM)

SVM can handle multiclass problems using strategies such as One-vs-One and One-vs-Rest.

### 8.6 Naive Bayes

Naive Bayes estimates probabilities for different classes and predicts a likely class.

### 8.7 Gradient Boosting

Popular multiclass-capable implementations include:

- XGBoost
- LightGBM
- CatBoost

## 9. How Do We Evaluate Multiclass Classification?

We need to measure how accurately the model predicts different classes.

Important evaluation metrics include:

### 9.1 Accuracy

Percentage of all predictions that are correct.

### 9.2 Precision

Measures how often predictions for a particular class are correct.

### 9.3 Recall

Measures how many actual examples of a particular class the model successfully identifies.

### 9.4 F1 Score

Combines Precision and Recall.

### 9.5 Confusion Matrix

A multiclass Confusion Matrix compares actual and predicted classes.

For example, with three classes:

- Cat
- Dog
- Horse

The matrix has three rows and three columns.

It helps us identify which classes the model confuses with one another.

### 9.6 Macro, Micro and Weighted Averages

When evaluating multiple classes, Precision, Recall and F1 Score can be averaged in different ways.

- Macro average: Calculates the metric separately for each class and gives every class equal weight.
- Micro average: Combines the contributions of all classes before calculating the metric.
- Weighted average: Gives each class weight according to its number of actual examples.

These averages are useful when classes have different numbers of examples.

## 11. Important Things to Remember

1. Multiclass Classification predicts one class from three or more possible classes.
2. It is a Supervised Learning technique.
3. Each training example has a correct target label.
4. The model can estimate probabilities for different classes.
5. The class with the highest predicted probability is commonly selected.
6. Logistic Regression, Decision Trees, Random Forest, KNN and SVM can be used.
7. Confusion Matrix helps evaluate predictions across multiple classes.
8. Macro, Micro and Weighted averages are useful evaluation methods.
