# Multilabel Classification — Complete Beginner Notes

## 1. What Is Multilabel Classification?

First, understand the word:

- Multi = Multiple
- Label = Category or tag

In Multilabel Classification, one input can have multiple correct labels at the same time.

**Simple definition:**

Multilabel Classification is a supervised machine learning task in which a model can assign multiple labels to a single input.

## 2. Understand With a Simple Example

Imagine you upload a photograph to an AI system.

The photograph contains:

- A dog
- A person
- A car
- A tree

The AI examines the photograph.

It predicts four labels:

1. Dog
2. Person
3. Car
4. Tree

All four labels can be correct for the same photograph.

This is Multilabel Classification.

Notice something important:

The model does not have to choose only one category.

It can predict several categories together.

## 3. Understand Input (X) and Output (Y)

Imagine we are building an AI model that identifies objects in photographs.

Our dataset looks like this:

| Photograph | Dog | Person | Car | Tree |
|---|---:|---:|---:|---:|
| Image 1 | 1 | 1 | 0 | 1 |
| Image 2 | 0 | 1 | 1 | 0 |
| Image 3 | 1 | 0 | 1 | 1 |
| Image 4 | 0 | 0 | 1 | 0 |

Here:

- Photograph = Input (X)
- Dog, Person, Car and Tree = Possible labels.
- 1 = Label is present.
- 0 = Label is absent.

For Image 1:

- Dog = 1
- Person = 1
- Car = 0
- Tree = 1

Therefore, its correct labels are:

Dog, Person and Tree.

One photograph has three correct labels.

## 4. How Does Multilabel Classification Work?

Let's understand step by step.

**Step 1: Provide training data**

We give the model many photographs with their correct labels.

**Step 2: The model learns**

It studies the photographs and learns patterns associated with different labels.

**Step 3: Provide a new photograph**

The model receives a photograph it has not seen before.

**Step 4: Predict multiple labels**

For example:

- Dog
- Person
- Tree

The model can predict all three labels for the same photograph.

## 5. How Does Probability Work?

A multilabel model can estimate a separate probability for each label.

Example:

A photograph contains several objects.

| Label | Predicted probability |
|---|---:|
| Dog | 95% |
| Person | 85% |
| Car | 20% |
| Tree | 90% |

Suppose we use a threshold of 50% for every label.

The predictions become:

- Dog: Selected
- Person: Selected
- Car: Not selected
- Tree: Selected

Final output:

Dog, Person and Tree.

Important:

Unlike ordinary single-label multiclass classification, multilabel probabilities do not need to add up to 100%. Each label is evaluated separately.

## 6. Binary vs Multiclass vs Multilabel Classification

This is one of the most important comparisons in classification.

| Type | Possible prediction |
|---|---|
| Binary | One of two classes |
| Multiclass | One class from three or more classes |
| Multilabel | Multiple labels for one input |

Let's understand using animal examples.

### Binary Classification

Question: Is this animal a Cat or Dog?

Possible answer:

Cat.

### Multiclass Classification

Question: Which animal is this?

Possible classes:

- Cat
- Dog
- Horse
- Elephant

Possible answer:

Dog.

Only one class is selected.

### Multilabel Classification

Question: Which objects or animals are present in this photograph?

Possible labels:

- Dog
- Cat
- Person
- Car

Possible answer:

Dog, Cat and Person.

Multiple labels can be selected.

## 7. Important Algorithms and Models

Multilabel Classification can be implemented using different approaches.

### 7.1 One Binary Classifier Per Label

We train a separate binary classifier for each label.

Example:

For a photograph, we train separate classifiers:

- Is there a Dog?
- Is there a Person?
- Is there a Car?
- Is there a Tree?

Each classifier predicts whether its label is present or absent.

### 7.2 Classifier Chains

Classifier Chains connect multiple classifiers.

The prediction from one classifier can be used as additional information by the next classifier.

This can help the model learn relationships between labels.

### 7.3 Multi-Output Models

Some machine learning algorithms can predict multiple outputs together.

Examples include suitable multi-output Decision Tree and Random Forest implementations.

### 7.4 Deep Learning Models

Neural networks can also perform multilabel classification.

For example, a neural network can have multiple output units, with each output predicting one label.

A common approach is to use a sigmoid activation for each output and Binary Cross-Entropy loss.

## 8. How Do We Evaluate Multilabel Classification?

Evaluating multilabel models requires considering multiple labels.

Important metrics include:

### 8.1 Hamming Loss

Measures how often individual label predictions are incorrect.

Lower Hamming Loss is better.

### 8.2 Exact Match Ratio

Measures how many examples have every predicted label exactly matching the actual labels.

A prediction is counted as correct only when the complete set of labels matches.

### 8.3 Precision

Measures how many predicted labels are actually correct.

### 8.4 Recall

Measures how many actual labels the model successfully identifies.

### 8.5 F1 Score

Combines Precision and Recall.

Common averaging methods include:

- Micro F1
- Macro F1
- Weighted F1
- Samples F1

## 10. Important Things to Remember

1. Multilabel Classification can assign multiple labels to one input.
2. It is a Supervised Learning technique.
3. Each input can have several correct labels.
4. Each label can be predicted independently.
5. Probabilities across labels do not need to add up to 100%.
6. Thresholds can decide whether individual labels are selected.
7. Binary classifiers, Classifier Chains and neural networks can be used.
8. Hamming Loss, Exact Match Ratio, Precision, Recall and F1 Score are important evaluation metrics.
