# K-Nearest Neighbors (KNN) Classifier — Complete Beginner Notes

## 1. What Is K-Nearest Neighbors?

K-Nearest Neighbors (KNN) is a supervised machine learning algorithm used for classification and regression.

It makes predictions by looking at the nearest examples in the training dataset.

Let's understand with a simple example.

Imagine you want to identify an unknown animal.

You already have examples of:

- Cats
- Dogs

A new animal arrives.

Instead of building complicated decision rules, KNN looks at the most similar animals in the existing dataset.

If most of the nearest examples are Dogs, it predicts Dog.

**Simple definition:**

K-Nearest Neighbors is a machine learning algorithm that makes predictions using the labels or values of the nearest training examples.

## 2. What Does K Mean?

K represents the number of nearest neighbors the algorithm considers when making a prediction.

For example:

- K = 1 means look at the nearest 1 example.
- K = 3 means look at the nearest 3 examples.
- K = 5 means look at the nearest 5 examples.
- K = 10 means look at the nearest 10 examples.

The value of K is selected before making predictions.

## 3. Understand With a Simple Example

Imagine we want to classify a new animal as Cat or Dog.

Our training dataset contains:

| Animal | Weight |

The three nearest examples are:

- Dog

- Dog

Final prediction:

**Dog**

The majority of the three nearest neighbors are Dogs.

## 4. How Does KNN Work?

Let's understand the complete process.

### Step 1: Store Training Data

KNN receives training examples with their features and correct labels.

### Step 2: Receive New Input

A new example arrives that needs a prediction.

### Step 3: Calculate Distances

The algorithm calculates how far the new example is from the existing training examples.

### Step 4: Find the Nearest Neighbors

It selects the K examples with the smallest distances.

### Step 5: Vote

For classification, the algorithm counts the class labels among those neighbors.

### Step 6: Predict

The class with the highest number of votes becomes the prediction.

## 5. What Is Distance?

Distance measures how far two examples are from each other.

KNN uses distance to identify similar examples.

Imagine two students:

- Student A: 5 study hours
- Student B: 6 study hours

Their study hours differ by 1.

Now consider:

- Student A: 5 study hours
- Student C: 10 study hours

Their study hours differ by 5.

Student B is closer to Student A based on study hours.

KNN uses mathematical distance calculations when multiple features are involved.

## 6. What Is Euclidean Distance?

Euclidean Distance is a common distance measurement used in KNN.

For two examples with two numerical features, it measures the straight-line distance between their points.

Example:

Point A = (2, 3)

Point B = (5, 7)

Their Euclidean Distance is:

\[
d = \sqrt{(5-2)^2+(7-3)^2}
\]

\[
d = \sqrt{9+16} = 5
\]

You do not need to memorize the equation immediately.

Remember:

Euclidean Distance measures the straight-line distance between two points.

Other distance measurements include:

- Manhattan Distance
- Minkowski Distance
- Hamming Distance

The suitable distance measurement depends on the type of data and problem.

## 7. What Happens When We Change K?

K is an important parameter.

Let's understand using a simple example.

Suppose the five nearest neighbors are:

| Neighbor | Class |
|---|---|
| 1 | Cat |
| 2 | Dog |
| 3 | Dog |
| 4 | Dog |
| 5 | Cat |

### When K = 1

Only the nearest neighbor is considered.

Prediction: Cat.

### When K = 3

The first three neighbors are considered.

- Cat = 1
- Dog = 2

Prediction: Dog.

### When K = 5

All five neighbors are considered.

- Cat = 2
- Dog = 3

Prediction: Dog.

Changing K can change the final prediction.

## 8. What Happens If K Is Too Small?

Suppose K = 1.

The model depends on only one neighboring example.

That example might be unusual or noisy.

As a result, the prediction can become sensitive to individual training examples.

Very small K values can lead to overfitting.

## 9. What Happens If K Is Too Large?

Suppose K is almost equal to the number of training examples.

The algorithm considers many distant examples.

This can make the prediction less sensitive to local patterns.

Very large K values can lead to underfitting.

Therefore, choosing a suitable K is important.

## 10. What Is Feature Scaling?

Feature scaling is particularly important for distance-based algorithms such as KNN.

Imagine a dataset containing:

- Age: 20 to 60
- Salary: 10,000 to 100,000

Salary has much larger numerical values than Age.

Without scaling, salary can dominate the distance calculation.

Feature scaling brings numerical features onto comparable scales.

Common methods include:

- Standardization
- Min-Max Scaling

KNN usually benefits from properly scaled numerical features.

## 11. What Is the Difference Between KNN and Decision Tree?

| KNN | Decision Tree |
|---|---|
| Uses nearby examples | Uses learned questions and conditions |
| Calculates distances | Searches for useful splits |
| Needs suitable feature scaling | Usually does not require feature scaling |
| Stores training examples for prediction | Learns a tree structure |
| K controls neighbors | max_depth controls tree depth |

## 12. Advantages of KNN

1. Easy to understand.
2. Simple to implement.
3. Can handle classification and regression.
4. No complicated model-training process is required.
5. Can model nonlinear decision boundaries.
6. Useful as a baseline model.

## 13. Limitations of KNN

1. Prediction can be slow for large datasets.
2. Requires storing training examples.
3. Sensitive to feature scaling.
4. Performance can be affected by irrelevant features.
5. Choosing the correct K is important.
6. Distance calculations become difficult with many dimensions.

## 14. Important KNN Parameters

### n_neighbors

Controls the number of nearest neighbors.

Example:

```python
KNeighborsClassifier(n_neighbors=5)
```

### weights

Controls how neighboring examples contribute to the prediction.

Common options:

- uniform: Every neighbor has equal voting weight.
- distance: Closer neighbors receive more voting weight.

### metric

Controls the distance measurement.

Examples:

- minkowski
- euclidean
- manhattan

### p

Controls the Minkowski distance power.

- p = 1 corresponds to Manhattan Distance.
- p = 2 corresponds to Euclidean Distance.

## 15. KNN Using Python

We can implement KNN using Scikit-Learn.

```python
from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

# Create the model
model = make_pipeline(
    StandardScaler(),
    KNeighborsClassifier(n_neighbors=5)
)

# Train the model
model.fit(X_train, y_train)

# Predict classes
predictions = model.predict(X_test)
```

Explanation:

- `StandardScaler()` scales numerical features.
- `KNeighborsClassifier()` creates the KNN model.
- `n_neighbors=5` selects five neighbors.
- `make_pipeline()` connects scaling and classification.
- `fit()` prepares the pipeline using training data.
- `predict()` predicts class labels.
