# Decision Tree Classifier — Complete Beginner Notes

## 1. What Is a Decision Tree?

A Decision Tree is a supervised machine learning algorithm used for classification and regression.

For classification, it predicts a category by following a sequence of questions or conditions.

Imagine you want to decide whether to carry an umbrella.

You ask:

1. Is it raining?
2. If yes, carry an umbrella.
3. If no, check whether rain is expected.

You are making a decision through questions.

A Decision Tree works in a similar way.

**Simple definition:**

A Decision Tree Classifier is a machine learning algorithm that predicts a class by following a series of learned questions and conditions.

## 2. Understand With a Simple Example

Imagine we want to predict whether a student will Pass or Fail.

We have information about students:

| Study hours | Attendance | Result |
|---:|---:|---|
| 1 | 40% | Fail |
| 2 | 50% | Fail |
| 3 | 60% | Fail |
| 5 | 80% | Pass |
| 6 | 90% | Pass |
| 8 | 95% | Pass |

The model studies this dataset.

It may learn conditions such as:

- Are study hours greater than 4?
- Is attendance greater than 70%?

When a new student arrives, the model follows its learned conditions and predicts Pass or Fail.

These conditions are learned from training data; they are not necessarily fixed in advance.

## 3. What Does a Decision Tree Look Like?

A Decision Tree looks like a tree with branches.

It contains three important parts:

### 3.1 Root Node

The Root Node is the starting point of the tree.

It contains the first question or condition.

### 3.2 Decision Nodes

Decision Nodes contain additional questions or conditions.

They divide the data into smaller groups.

### 3.3 Leaf Nodes

Leaf Nodes are the final points of the tree.

They contain the predicted class.

Example:

```text
             Study hours > 4?
                /       \
              No         Yes
              /           \
            Fail       Attendance > 70%?
                         /       \
                       No         Yes
                       /           \
                     Fail          Pass
```

This is an illustrative decision tree.

## 4. How Does a Decision Tree Learn?

The model does not randomly create questions.

It examines the training dataset and searches for useful ways to divide the examples.

Let's understand step by step.

**Step 1: Receive training data**

The model receives features and their correct class labels.

**Step 2: Examine possible conditions**

For example:

- Study hours greater than 2?
- Study hours greater than 4?
- Attendance greater than 60%?

**Step 3: Evaluate the splits**

The model measures how well each condition separates different classes.

**Step 4: Select a useful split**

It chooses a condition that improves the separation of the data.

**Step 5: Repeat**

It continues dividing the data into smaller groups.

**Step 6: Create leaf nodes**

The tree reaches final predictions.

## 5. What Is Splitting?

Splitting means dividing a dataset into smaller groups using a condition.

Example:

Suppose we have 10 students:

- 5 Pass
- 5 Fail

We divide them using:

Study hours greater than 4?

The resulting groups might be:

Group A:
- 1 Pass
- 4 Fail

Group B:
- 4 Pass
- 1 Fail

The split separates the two classes reasonably well.

The Decision Tree evaluates possible splits and selects one according to its splitting criterion.

## 6. What Is Gini Impurity?

Gini Impurity measures how mixed the classes are inside a group.

Imagine a group containing:

- 5 Pass
- 5 Fail

Both classes are equally represented.

This group is highly mixed.

Now imagine another group:

- 9 Pass
- 1 Fail

This group is much less mixed.

A group containing only one class has zero Gini Impurity.

**Remember:**

- Lower Gini Impurity = More pure group.
- Higher Gini Impurity = More mixed group.

The Decision Tree can use Gini Impurity to evaluate splits.

## 7. What Is Entropy?

Entropy is another measurement used to understand how mixed a group is.

For classification:

- High entropy means the classes are more mixed.
- Low entropy means one class dominates.
- Zero entropy means the group contains only one class.

Decision Trees can use entropy to evaluate possible splits.

## 8. Gini Impurity vs Entropy

Both help a Decision Tree measure the quality of a split.

| Gini Impurity | Entropy |
|---|---|
| Measures class impurity | Measures class uncertainty |
| Lower is better | Lower is better |
| Common split criterion | Another common split criterion |
| Used in CART implementations | Used in algorithms such as ID3 |

Both can produce useful classification trees.

## 9. What Is Information Gain?

Information Gain measures how much uncertainty is reduced after splitting a dataset.

Imagine:

Before splitting:
- The dataset contains Pass and Fail examples mixed together.

After splitting:
- One group contains mostly Pass.
- Another group contains mostly Fail.

The uncertainty has decreased.

That reduction is called Information Gain.

A split with higher Information Gain is generally preferred when using this criterion.

## 10. Important Decision Tree Parameters

When training a Decision Tree, we can control its structure.

### 10.1 max_depth

Controls the maximum depth of the tree.

A very deep tree can learn too many details from the training data.

### 10.2 min_samples_split

Controls the minimum number of samples required to split an internal node.

### 10.3 min_samples_leaf

Controls the minimum number of samples required in a leaf node.

### 10.4 criterion

Controls the splitting measurement.

Common options in Scikit-Learn include:

- gini
- entropy
- log_loss

## 11. What Is Overfitting in a Decision Tree?

Overfitting happens when a model learns the training examples too closely, including unnecessary details and noise.

Imagine a Decision Tree that grows very deep.

It may correctly classify almost every training example but perform poorly on new examples.

This is overfitting.

We can reduce it using:

- max_depth
- min_samples_split
- min_samples_leaf
- Pruning

## 12. What Is Pruning?

Pruning means removing unnecessary branches from a Decision Tree.

Why?

A very complicated tree may memorize training examples instead of learning useful general patterns.

Pruning simplifies the tree and can improve its ability to generalize to new data.

Two common approaches:

- Pre-pruning: Stop the tree from growing too much.
- Post-pruning: Grow the tree and then remove unnecessary branches.

## 13. Advantages of Decision Trees

1. Easy to understand.
2. Easy to visualize.
3. Can handle numerical and categorical features with suitable preprocessing or implementation.
4. Can model nonlinear decision boundaries.
5. Usually requires less feature scaling than many other algorithms.
6. Can be used for classification and regression.

## 14. Limitations of Decision Trees

1. Deep trees can overfit.
2. Small changes in training data can produce different trees.
3. A single tree may have lower predictive performance than an ensemble.
4. Greedy splitting does not guarantee the globally optimal tree.
5. Large trees can become difficult to interpret.

## 15. Decision Tree Using Python

We can implement a Decision Tree Classifier using Scikit-Learn.

```python
from sklearn.tree import DecisionTreeClassifier

# Create the model
model = DecisionTreeClassifier(
    criterion="gini",
    max_depth=3,
    random_state=42
)

# Train the model
model.fit(X_train, y_train)

# Predict classes
predictions = model.predict(X_test)
```

Explanation:

- `DecisionTreeClassifier()` creates the model.
- `criterion="gini"` selects Gini Impurity.
- `max_depth=3` limits the tree depth.
- `fit()` trains the model.
- `predict()` predicts class labels.
