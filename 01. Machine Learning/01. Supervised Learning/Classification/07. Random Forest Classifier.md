# Random Forest Classifier — Complete Beginner Notes

## 1. What Is Random Forest?

Random Forest is a supervised machine learning algorithm used for classification and regression.

It creates multiple Decision Trees and combines their predictions to produce a final result.

**Simple definition:**

Random Forest is an ensemble learning algorithm that combines multiple Decision Trees to make predictions.

## 2. Why Do We Need Random Forest?

Let's remember Decision Trees.

A Decision Tree learns from training data and creates questions to make predictions.

However, a single Decision Tree can sometimes make unreliable predictions.

For example:

Imagine we train one Decision Tree to predict whether a customer will purchase a product.

The tree predicts:

Will Purchase.

But another Decision Tree trained on slightly different data might predict:

Will Not Purchase.

Different trees can learn different patterns.

Random Forest uses multiple trees together to make a combined prediction.

## 3. Understand With a Simple Example

Imagine a bank wants to predict whether a transaction is fraudulent.

Instead of using only one Decision Tree, Random Forest uses 5 trees.

Each tree makes its own prediction.

| Decision Tree | Prediction |
|---|---|
| Tree 1 | Fraud |
| Tree 2 | Fraud |
| Tree 3 | Genuine |
| Tree 4 | Fraud |
| Tree 5 | Genuine |

Now count the predictions:

- Fraud = 3 votes
- Genuine = 2 votes

The final prediction is:

**Fraud**

Why?

Because Fraud received the majority of votes.

This is called majority voting.

## 4. How Does Random Forest Work?

Let's understand the process step by step.

### Step 1: Provide Training Data

We give the algorithm a dataset containing input features and their correct labels.

### Step 2: Create Multiple Training Samples

Random Forest creates different training samples using a method called Bootstrap Sampling.

Each sample is used to train a separate Decision Tree.

### Step 3: Train Multiple Decision Trees

Each tree learns from its own training sample.

### Step 4: Use Random Feature Selection

When searching for a split, each tree considers a randomly selected subset of features rather than always considering every feature.

This helps create diversity between trees.

### Step 5: Make Predictions

Each Decision Tree makes its own prediction.

### Step 6: Combine Predictions

For classification, Random Forest generally uses majority voting.

The class receiving the most votes becomes the final prediction.

## 5. What Is Bootstrap Sampling?

Bootstrap Sampling means creating a training sample by randomly selecting examples from the original dataset with replacement.

What does "with replacement" mean?

It means the same example can be selected more than once.

Imagine the original dataset contains:

A, B, C, D, E

One bootstrap sample might contain:

A, B, B, D, E

Another might contain:

A, C, C, D, D

Each sample can be different.

These samples help create different Decision Trees.

## 6. What Is Random Feature Selection?

Imagine our dataset contains these features:

- Age
- Salary
- Education
- Credit Score
- Employment Status

A Decision Tree may consider all available features when searching for a split.

In Random Forest, each split considers a randomly selected subset of features.

For example:

Tree 1 might consider:
- Age
- Salary

Tree 2 might consider:
- Education
- Credit Score

Tree 3 might consider:
- Salary
- Employment Status

The selected features vary between splits and trees.

This encourages diversity among the Decision Trees.

## 7. What Is Ensemble Learning?

Ensemble Learning means combining multiple machine learning models to produce a prediction.

Instead of depending on only one model, we use several models together.

Random Forest is an example of Ensemble Learning.

Other examples include:

- Voting Classifier
- Bagging
- Boosting
- Gradient Boosting
- XGBoost
- LightGBM
- CatBoost

## 8. What Is Bagging?

Bagging stands for Bootstrap Aggregating.

It involves:

1. Creating multiple bootstrap samples.
2. Training separate models on those samples.
3. Combining their predictions.

Random Forest is a Bagging-based ensemble of Decision Trees that also uses random feature selection.

## 9. How Does Random Forest Produce Probabilities?

Random Forest can also estimate class probabilities.

Imagine five trees predict:

| Tree | Fraud | Genuine |
|---|---:|---:|
| Tree 1 | 100% | 0% |
| Tree 2 | 100% | 0% |
| Tree 3 | 100% | 0% |
| Tree 4 | 0% | 100% |
| Tree 5 | 0% | 100% |

The average probabilities are:

- Fraud = 60%
- Genuine = 40%

The final predicted class is Fraud.

These are illustrative values. In Scikit-Learn, Random Forest classification probabilities are generally calculated by averaging the individual trees' class probabilities.

## 10. Important Random Forest Parameters

### 10.1 n_estimators

Controls the number of Decision Trees.

Example:

```python
RandomForestClassifier(n_estimators=100)
```

This creates 100 trees.

### 10.2 max_depth

Controls the maximum depth of each Decision Tree.

### 10.3 max_features

Controls how many features are considered when searching for each split.

### 10.4 min_samples_split

Controls the minimum number of samples required to split a node.

### 10.5 min_samples_leaf

Controls the minimum number of samples required in a leaf node.

### 10.6 bootstrap

Controls whether bootstrap sampling is used to build trees.

## 11. What Is Feature Importance?

Random Forest can estimate how useful different features were for making predictions.

Imagine a fraud detection model uses:

- Transaction Amount
- Location
- Transaction Time
- Account Age

An example feature importance ranking might be:

| Feature | Importance |
|---|---:|
| Transaction Amount | 40% |
| Location | 30% |
| Transaction Time | 20% |
| Account Age | 10% |

This suggests Transaction Amount contributed more to the model's tree-based splitting decisions.

Important: These percentages are illustrative. Feature importance does not prove that a feature causes fraud, and impurity-based importance can be biased in some situations.

## 12. Advantages of Random Forest

1. Combines multiple Decision Trees.
2. Often provides better generalization than a single Decision Tree.
3. Can model complex nonlinear relationships.
4. Can handle many input features.
5. Provides feature importance estimates.
6. Can perform classification and regression.
7. Usually requires little feature scaling.

## 13. Limitations of Random Forest

1. Uses more memory than a single Decision Tree.
2. Can require more time to train.
3. Predictions can be slower when many trees are used.
4. Harder to interpret than one small Decision Tree.
5. Can perform poorly when the data or features are unsuitable.
6. Feature importance needs careful interpretation.

## 14. Decision Tree vs Random Forest

| Decision Tree | Random Forest |
|---|---|
| Uses one tree | Uses multiple trees |
| Makes one tree's prediction | Combines tree predictions |
| Easier to visualize | More difficult to visualize |
| Can overfit easily | Often reduces overfitting |
| Lower computational cost | Higher computational cost |
| Single-model algorithm | Ensemble algorithm |

## 15. Random Forest Using Python

We can implement Random Forest using Scikit-Learn.

```python
from sklearn.ensemble import RandomForestClassifier

# Create the model
model = RandomForestClassifier(
    n_estimators=100,
    max_depth=5,
    random_state=42
)

# Train the model
model.fit(X_train, y_train)

# Predict classes
predictions = model.predict(X_test)

# Predict probabilities
probabilities = model.predict_proba(X_test)
```

Explanation:

- `RandomForestClassifier()` creates the model.
- `n_estimators=100` creates 100 trees.
- `max_depth=5` limits the depth of each tree.
- `fit()` trains the model.
- `predict()` predicts class labels.
- `predict_proba()` predicts class probabilities.
