# Logistic Regression — Complete Beginner Notes

## 1. What Is Logistic Regression?

Logistic Regression is a supervised machine learning algorithm commonly used for classification.

It predicts the probability that an input belongs to a particular class.

Example:

Imagine a bank wants to predict whether a customer will repay a loan.

There are two possible classes:

- Will Repay
- Will Not Repay

The model examines customer information and estimates the probability of each outcome.

**Simple definition:**

Logistic Regression is a classification algorithm that estimates the probability of an input belonging to a class.

## 2. Why Is It Called Logistic Regression?

The name can be confusing.

You might think:

"If it contains Regression in its name, why is it used for Classification?"

The reason is that the algorithm uses a mathematical function called the Logistic Function to produce probabilities.

Those probabilities are then used to make classification decisions.

Remember:

- Linear Regression generally predicts numerical values.
- Logistic Regression generally predicts class probabilities.

Despite its name, Logistic Regression is commonly used as a classification algorithm.

## 3. Understand With a Simple Example

Imagine we want to predict whether a student will pass an examination.

We collect information:

| Study hours | Result |
|---:|---|
| 1 | Fail |
| 2 | Fail |
| 3 | Fail |
| 5 | Pass |
| 6 | Pass |
| 8 | Pass |

The model learns from these examples.

Now we give it a new student:

Study hours = 6

The model estimates:

Probability of Pass = 90%.

If our decision threshold is 50%, the model predicts:

Pass.

This is how Logistic Regression can be used for Binary Classification.

Note: These example probabilities are illustrative, not calculated from a trained model.

## 4. What Does Logistic Regression Predict?

Logistic Regression predicts a probability.

For example:

| Input | Probability of Pass |
|---|---:|
| Student A | 20% |
| Student B | 45% |
| Student C | 70% |
| Student D | 95% |

The model produces a probability between 0 and 1.

In percentage form, this means between 0% and 100%.

Examples:

- 0.20 = 20%
- 0.50 = 50%
- 0.80 = 80%
- 0.95 = 95%

## 5. What Is the Sigmoid Function?

The Sigmoid Function is one of the most important concepts in Logistic Regression.

It converts a numerical input into a value between 0 and 1.

Think about it this way:

A model calculates a score.

But that score might be:

- -5
- -2
- 0
- 3
- 8

These numbers are not probabilities.

The Sigmoid Function transforms the score into a probability.

For example:

| Model score | Approximate sigmoid output |
|---:|---:|
| -5 | 0.007 |
| -2 | 0.119 |
| 0 | 0.500 |
| 2 | 0.881 |
| 5 | 0.993 |

The outputs are between 0 and 1.

Therefore, they can be interpreted as estimated probabilities for the positive class.

## 6. What Is a Decision Threshold?

A probability alone does not automatically decide the final class.

We use a decision threshold.

Suppose the threshold is 0.50.

Our decision rule is:

- Probability greater than or equal to 0.50 → Positive.
- Probability below 0.50 → Negative.

Example:

| Predicted probability | Final prediction |
|---:|---|
| 0.90 | Positive |
| 0.80 | Positive |
| 0.65 | Positive |
| 0.50 | Positive |
| 0.30 | Negative |
| 0.10 | Negative |

The threshold can be changed depending on the problem.

For example, in some fraud detection systems, we may choose a lower threshold to catch more potentially fraudulent transactions.

## 7. How Does Logistic Regression Work?

Let's understand the process.

**Step 1: Provide training data**

The model receives input features and their correct class labels.

**Step 2: Calculate a score**

It combines the input features using learned weights and a bias.

**Step 3: Apply the Sigmoid Function**

The score is converted into a probability.

**Step 4: Apply a decision threshold**

The probability is compared with the selected threshold.

**Step 5: Produce a class prediction**

The model predicts Positive or Negative.

## 8. What Are Features, Weights and Bias?

Logistic Regression learns relationships between input features and the target.

### Features

Features are the input information.

Example:

- Study hours
- Attendance
- Previous examination marks

### Weights

Weights represent the learned contribution of each feature to the model's score.

A larger positive weight increases the score as that feature increases, assuming other features remain unchanged.

A negative weight decreases the score as that feature increases.

### Bias

Bias is an additional learned value used when calculating the model's score.

It allows the model's decision boundary to shift.

## 9. Logistic Regression Formula

The model first calculates a score:

z = b + w₁x₁ + w₂x₂ + ... + wₙxₙ

Where:

- x = Input features
- w = Learned weights
- b = Bias
- z = Model score

Then it applies the Sigmoid Function:

P = 1 / (1 + e⁻ᶻ)

Where:

- P = Predicted probability of the positive class
- e = Mathematical constant
- z = Model score

You do not need to memorize the mathematics immediately. First understand the process:

Input features → Model score → Sigmoid → Probability → Class prediction.

## 10. How Does Logistic Regression Learn?

During training, Logistic Regression adjusts its weights and bias to improve its predictions.

A common approach is to use a loss function called Log Loss (Binary Cross-Entropy).

The model attempts to reduce the difference between its predicted probabilities and the correct labels.

The optimization algorithm updates the model's parameters repeatedly until it finds suitable values.

## 11. What Is Log Loss?

Log Loss measures how well the model's predicted probabilities match the actual labels.

For example:

Actual class = Positive.

Prediction A = 0.95 probability of Positive.

Prediction B = 0.20 probability of Positive.

Prediction A is better because it assigns a higher probability to the correct class.

Log Loss penalizes confident incorrect predictions particularly strongly.

Lower Log Loss is generally better.

## 12. Types of Logistic Regression

There are three commonly discussed types.

### 12.1 Binary Logistic Regression

Used when there are exactly two possible classes.

Examples:

- Spam / Not Spam
- Pass / Fail
- Fraud / Genuine

### 12.2 Multinomial Logistic Regression

Used when there are three or more mutually exclusive classes.

Examples:

- Cat / Dog / Horse
- Sports / Politics / Business

It can use the Softmax Function to produce probabilities across multiple classes.

### 12.3 Ordinal Logistic Regression

Used when classes have a meaningful order.

Example:

- Low
- Medium
- High

The categories have a natural ranking.

## 13. Advantages of Logistic Regression

1. Simple to understand.
2. Fast to train on many datasets.
3. Produces class probabilities.
4. Works well as a baseline classification model.
5. Its learned coefficients can help interpret feature relationships.
6. Supports regularization to control model complexity.

## 14. Limitations of Logistic Regression

1. It learns a linear decision boundary in its feature space.
2. It may struggle with complex nonlinear relationships unless features are transformed.
3. Performance can be affected by irrelevant or poorly prepared features.
4. It can struggle when classes are difficult to separate using the available features.
5. It may require feature engineering for complicated problems.

## 15. Logistic Regression Using Python

We can implement Logistic Regression using Scikit-Learn.

Example:

```python
from sklearn.linear_model import LogisticRegression

# Create the model
model = LogisticRegression()

# Train the model
model.fit(X_train, y_train)

# Predict classes
predictions = model.predict(X_test)

# Predict probabilities
probabilities = model.predict_proba(X_test)
```

Explanation:

- `LogisticRegression()` creates the model.
- `fit()` trains the model.
- `predict()` predicts class labels.
- `predict_proba()` predicts class probabilities.

Here, `X_train`, `y_train` and `X_test` represent prepared training and testing data.
