# Naive Bayes Classifier — Complete Beginner Notes

## 1. What Is Naive Bayes?

Naive Bayes is a supervised machine learning algorithm commonly used for classification.

It uses probability to predict the most likely class for a given input.

Let's understand with an example.

Imagine you receive an email.

The email contains these words:

- Free
- Prize
- Winner
- Claim

You want to predict whether this email is:

- Spam
- Not Spam

Naive Bayes examines the words and uses patterns learned from previously labelled emails to estimate the probability of each class.

It then predicts the most likely category.

**Simple definition:**

Naive Bayes is a probabilistic classification algorithm based on Bayes' Theorem and a simplifying assumption that features are conditionally independent given the class.

## 2. Why Is It Called Naive Bayes?

The name contains two parts.

### Bayes

Bayes refers to Bayes' Theorem, a mathematical rule for calculating probabilities using existing information.

### Naive

Naive refers to a simplifying assumption:

The algorithm assumes that input features are conditionally independent of one another when the class is known.

For example, in an email:

- Free
- Prize
- Winner

The algorithm treats these words as independent pieces of evidence once the email's class is known.

In real life, words can be related to one another.

This assumption is not always true, but Naive Bayes can still work surprisingly well.

## 3. Understand With a Simple Example

Imagine we have a dataset of emails.

Some emails are Spam, and others are Not Spam.

| Email | Contains "Free"? | Class |
|---|---|---|
| Email 1 | Yes | Spam |
| Email 2 | Yes | Spam |
| Email 3 | Yes | Spam |
| Email 4 | No | Not Spam |
| Email 5 | No | Not Spam |
| Email 6 | Yes | Not Spam |

Now a new email arrives.

It contains the word:

Free.

The model examines how often this word appeared in Spam and Not Spam emails in its training data.

It uses this information to estimate which class is more likely.

This is the basic idea behind Naive Bayes.

## 4. What Is Probability?

Probability measures how likely something is to happen.

It ranges from 0 to 1.

Examples:

| Probability | Meaning |
|---|---|
| 0 | Impossible |
| 0.25 | 25% chance |
| 0.50 | 50% chance |
| 0.75 | 75% chance |
| 1 | Certain |

Naive Bayes uses probabilities to make predictions.

## 5. What Is Bayes' Theorem?

Bayes' Theorem is the mathematical foundation of Naive Bayes.

It helps calculate the probability of a class after observing some information.

The formula is:

P(Class | Features) = P(Features | Class) × P(Class) / P(Features)

Let's understand each part.

### P(Class | Features)

The probability of a class after observing the features.

Example:

The probability that an email is Spam after seeing the word "Free".

### P(Features | Class)

The probability of observing those features when the class is known.

Example:

How often the word "Free" appears in Spam emails.

### P(Class)

The prior probability of the class.

Example:

How many emails in the training dataset are Spam.

### P(Features)

The overall probability of observing the features.

Example:

How often the word "Free" appears across all emails.

You do not need to memorize the equation immediately.

Remember the main idea:

Bayes' Theorem updates a probability using new information.

## 6. How Does Naive Bayes Work?

Let's understand the process step by step.

**Step 1: Provide Training Data**

We give the model examples with their correct class labels.

**Step 2: Learn Class Probabilities**

The model calculates how common each class is.

Example:

- Spam = 60%
- Not Spam = 40%

**Step 3: Learn Feature Probabilities**

The model examines how frequently different features occur in each class.

Example:

How frequently does the word "Free" appear in Spam emails?

How frequently does it appear in Not Spam emails?

**Step 4: Receive New Input**

A new email arrives containing certain words.

**Step 5: Calculate Class Probabilities**

The model uses Bayes' Theorem to estimate the probability of each class.

**Step 6: Predict**

The model chooses the class with the highest estimated probability.

## 7. What Is Conditional Independence?

This is the important assumption behind Naive Bayes.

Imagine an email contains three words:

- Free
- Prize
- Winner

The algorithm assumes that these features are conditionally independent given the email's class.

In simple language:

Once we know whether the email is Spam or Not Spam, the model treats each word as separate evidence.

Real-world words can be related, so this assumption is often imperfect.

However, the algorithm can still perform well.

## 8. What Is Laplace Smoothing?

Imagine a word has never appeared in Spam emails in the training dataset.

Its estimated probability may become zero.

This creates a problem.

If Naive Bayes multiplies probabilities and one probability is zero, the entire product can become zero.

Laplace Smoothing helps solve this problem.

It adds a small amount to the observed counts so that unseen features do not automatically receive zero probability.

It is commonly used in Multinomial Naive Bayes.

## 9. Types of Naive Bayes

There are several types of Naive Bayes algorithms.

### 9.1 Gaussian Naive Bayes

Used mainly for continuous numerical features.

Examples:

- Height
- Weight
- Temperature
- Blood pressure

It assumes that each numerical feature follows a Gaussian (normal) distribution within each class.

### 9.2 Multinomial Naive Bayes

Commonly used for count-based data.

Example:

Spam email detection using word counts.

It is especially useful in text classification.

### 9.3 Bernoulli Naive Bayes

Used for binary features.

Example:

| Word | Present? |
|---|---|
| Free | 1 |
| Prize | 0 |
| Winner | 1 |

Here:

- 1 = Word is present.
- 0 = Word is absent.

### 9.4 Complement Naive Bayes

A variation of Multinomial Naive Bayes.

It is designed to improve performance in some imbalanced text classification problems.

## 10. Gaussian vs Multinomial vs Bernoulli

| Type | Common data |
|---|---|
| Gaussian Naive Bayes | Continuous numerical features |
| Multinomial Naive Bayes | Counts and frequencies |
| Bernoulli Naive Bayes | Binary features |
| Complement Naive Bayes | Count-based, often imbalanced text data |

Choosing the appropriate type depends on the data representation.

## 11. Advantages of Naive Bayes

1. Simple to understand.
2. Fast to train.
3. Fast to make predictions.
4. Works well for many text classification tasks.
5. Can work with relatively small datasets.
6. Supports multiclass classification.
7. Produces class probability estimates.

## 12. Limitations of Naive Bayes

1. Its independence assumption may not match real-world data.
2. Correlated features can affect predictions.
3. Zero-frequency problems require smoothing.
4. Probability estimates may not always be well calibrated.
5. Performance can be poor when the chosen feature distribution is unsuitable.

## 13. Naive Bayes Using Python

We can implement Naive Bayes using Scikit-Learn.

### Example 1: Gaussian Naive Bayes

```python
from sklearn.naive_bayes import GaussianNB

# Create the model
model = GaussianNB()

# Train the model
model.fit(X_train, y_train)

# Predict classes
predictions = model.predict(X_test)

# Predict probabilities
probabilities = model.predict_proba(X_test)
```

### Example 2: Multinomial Naive Bayes

```python
from sklearn.naive_bayes import MultinomialNB

# Create the model
model = MultinomialNB()

# Train the model
model.fit(X_train, y_train)

# Predict classes
predictions = model.predict(X_test)
```

Explanation:

- `GaussianNB()` creates a Gaussian Naive Bayes model.
- `MultinomialNB()` creates a Multinomial Naive Bayes model.
- `fit()` trains the model.
- `predict()` predicts class labels.
- `predict_proba()` estimates class probabilities.

For Multinomial Naive Bayes, features are generally non-negative counts or frequencies.

## 15. Naive Bayes vs Logistic Regression

| Naive Bayes | Logistic Regression |
|---|---|
| Uses Bayes' Theorem | Uses a logistic model |
| Models class probabilities using feature distributions | Models class probabilities using learned coefficients |
| Makes a conditional independence assumption in its standard form | Does not require that assumption |
| Often useful for text classification | Useful as a general classification baseline |
| Can work well with limited data | Often benefits from sufficient representative training data |
