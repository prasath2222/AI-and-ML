
# Gradient Boosting Regression

## 1. What Is Gradient Boosting Regression?

Imagine you want to predict house prices.

Your actual house price is:

```python
actual_price = 50
```

Your model makes this prediction:

```python
prediction = 30
```

The error is:

```python
error = actual_price - prediction

print(error)

# 20
```

Your model predicted 30 lakhs, but the actual price is 50 lakhs.

There is an error of 20 lakhs.

Now imagine you train another model to help correct this error.

The new model learns from the information about the previous model's mistakes.

This is the central idea behind Gradient Boosting.

### Simple definition

Gradient Boosting is an ensemble machine learning algorithm that builds models sequentially, with each new model attempting to improve the predictions of the existing model by learning from its remaining errors or gradients.

It commonly uses Decision Trees as its individual models.

---

# 2. Understanding the Main Idea With a Simple Example

Suppose the actual house price is:

```text
Actual price = 50 lakhs
```

Your initial model predicts:

```text
Prediction = 30 lakhs
```

The prediction is too low.

The remaining error is:

```text
50 - 30 = 20 lakhs
```

Now a second model learns to predict a correction.

For illustration:

```text
Correction = +15 lakhs
```

The combined prediction becomes:

```text
30 + 15 = 45 lakhs
```

There is still an error:

```text
50 - 45 = 5 lakhs
```

A third model attempts to correct the remaining error.

For illustration:

```text
Correction = +4 lakhs
```

The prediction becomes:

```text
45 + 4 = 49 lakhs
```

The remaining error is now:

```text
50 - 49 = 1 lakh
```

Look at the progression:

| Stage | Prediction | Actual price | Remaining error |
|---|---:|---:|---:|
| Initial model | 30 | 50 | 20 |
| After tree 1 | 45 | 50 | 5 |
| After tree 2 | 49 | 50 | 1 |

This is an illustrative example of sequential corrections.

Real Gradient Boosting trains trees using the errors or gradients across the training dataset, not by manually adding a correction to one house.

---

# 3. Understanding Why It Is Called Boosting

The word boosting means improving a model by combining multiple weaker models.

A single small Decision Tree might not predict house prices very accurately.

But several small trees can work together.

For example:

```text
Initial Prediction
        |
        v
    Decision Tree 1
        |
        v
  Improved Prediction
        |
        v
    Decision Tree 2
        |
        v
  Improved Prediction
        |
        v
    Decision Tree 3
        |
        v
   Final Prediction
```

Each new tree is added to the existing model.

The trees work together to create the final prediction.

This is called **sequential ensemble learning**.

---

# 4. Understanding the Initial Prediction

Before training its first correction tree, Gradient Boosting needs an initial prediction.

For ordinary regression using squared-error loss, this initial prediction is usually the mean of the target values.

Let's use your house-price dataset.

| House | Actual price |
|---|---:|
| A | 20 |
| B | 30 |
| C | 40 |
| D | 50 |
| E | 60 |

Calculate the mean:

\[
\text{Mean}=\frac{20+30+40+50+60}{5}
\]

\[
\text{Mean}=40
\]

Therefore, the initial prediction is:

```text
Initial prediction = 40 lakhs
```

Before the correction trees are added, the model predicts 40 lakhs for every house.

Let's calculate the initial residuals.

| House | Actual price | Initial prediction | Residual |
|---|---:|---:|---:|
| A | 20 | 40 | -20 |
| B | 30 | 40 | -10 |
| C | 40 | 40 | 0 |
| D | 50 | 40 | +10 |
| E | 60 | 40 | +20 |

Remember:

\[
\text{Residual}=\text{Actual}-\text{Prediction}
\]

The residual tells us how far the prediction is from the actual value and in which direction.

- Negative residual: prediction is too high.
- Positive residual: prediction is too low.
- Zero residual: prediction is correct.

The next tree attempts to learn patterns in these remaining errors.

---

# 5. Understanding the First Correction Tree

The initial prediction is 40 lakhs for every house.

But the predictions are not correct for all houses.

Let's look at the residuals:

| House size | Residual |
|---:|---:|
| 1000 | -20 |
| 1500 | -10 |
| 2000 | 0 |
| 2500 | +10 |
| 3000 | +20 |

The correction tree can learn a relationship between house size and residuals.

For example, imagine it learns:

```text
Is house size <= 2000?

       Yes              No
        |                |
  Correction = -10  Correction = +10
```

This is an illustrative tree, not a guaranteed result.

The tree has learned that:

- Smaller houses need a negative correction.
- Larger houses need a positive correction.

Now the model adds a scaled contribution from this tree.

Suppose:

```python
learning_rate = 0.1
```

For a smaller house:

\[
40+(0.1\times-10)=39
\]

For a larger house:

\[
40+(0.1\times10)=41
\]

The new predictions become:

| House size | Old prediction | Correction | New prediction |
|---:|---:|---:|---:|
| 1000 | 40 | -1 | 39 |
| 1500 | 40 | -1 | 39 |
| 2000 | 40 | -1 | 39 |
| 2500 | 40 | +1 | 41 |
| 3000 | 40 | +1 | 41 |

This example shows the basic idea of updating predictions using a tree.

In an actual fitted Gradient Boosting model, the tree's splits and leaf values are determined by the training algorithm.

---

# 6. Understanding the Second Tree

After the first tree, the model still makes errors.

The model calculates the new residuals.

The next tree learns from these remaining errors.

The process looks like this:

```text
Initial prediction
        |
        v
Calculate residuals
        |
        v
Train first correction tree
        |
        v
Update predictions
        |
        v
Calculate new residuals
        |
        v
Train second correction tree
        |
        v
Update predictions
        |
        v
Continue...
```

This continues until the configured number of boosting stages is reached or another stopping condition is met.

### Important

The second tree does not simply repeat the first tree.

It receives updated information about the errors remaining after the first tree has been added.

That is why sequential training matters.

---

# 7. Understanding Gradient Descent in Gradient Boosting

You already learned Gradient Descent.

Remember its main idea?

Gradient Descent tries to reduce a model's loss by moving in a direction that improves the predictions.

Gradient Boosting applies a related idea.

Instead of directly updating only ordinary numerical weights, it builds new trees that approximate the direction in which the predictions should change to reduce the loss.

These directions are calculated using gradients of the loss function.

### What is a gradient?

A gradient tells us how the loss changes when a prediction changes.

For Gradient Boosting, the algorithm uses the negative gradient of the loss to decide what the next tree should learn.

This is sometimes called the **pseudo-residual**.

For squared-error loss, the negative gradient is proportional to:

```text
Actual value - Predicted value
```

That is why, in the simple squared-error example, we can understand the process by looking at residuals.

### Important distinction

Gradient Boosting does not always train the next tree directly on ordinary residuals.

It trains the next tree to approximate the negative gradient of the selected loss function.

For squared-error regression, these quantities are closely related.

For other loss functions, they can be different.

# 8. Understanding the Gradient Boosting Prediction Formula

A simplified prediction formula is:

\[
F_M(x)=F_0(x)+
\eta\sum_{m=1}^{M}h_m(x)
\]

Understand each symbol:

| Symbol | Meaning |
|---|---|
| \(F_M(x)\) | Final prediction |
| \(F_0(x)\) | Initial prediction |
| \(\eta\) | Learning rate |
| \(M\) | Number of boosting stages |
| \(h_m(x)\) | Contribution from the tree at stage m |
| \(x\) | Input features |

In simple words:

```text
Final prediction =
Initial prediction
+
Tree 1 contribution
+
Tree 2 contribution
+
Tree 3 contribution
...
```

The learning rate controls how strongly each tree contributes.

This is the central mathematical idea behind Gradient Boosting.

---

# 9. Learning Rate in Gradient Boosting

You have already learned about learning rate in Gradient Descent.

Here, learning rate has a related purpose.

It controls how much each newly trained tree contributes to the existing model.

Example:

```python
learning_rate = 0.1
```

Suppose a tree predicts a correction of 20.

The contribution becomes:

```text
0.1 × 20 = 2
```

The model adds 2, not the full 20.

### Small learning rate

```python
learning_rate = 0.01
```

Each tree contributes a smaller correction.

This often requires more trees.

### Large learning rate

```python
learning_rate = 0.5
```

Each tree contributes a larger correction.

This may learn faster, but can make training less controlled and increase the risk of overfitting.

### Important relationship

Learning rate and number of trees are closely connected.

| Learning rate | Number of trees |
|---|---|
| Smaller | Often requires more trees |
| Larger | May require fewer trees |

There is no universal best combination.

You should tune both using validation or cross-validation.

---

# 10. Understanding n_estimators

In Gradient Boosting, `n_estimators` controls the number of boosting stages.

For the standard scikit-learn GradientBoostingRegressor, each stage adds one new regression tree.

Example:

```python
n_estimators = 10
```

The model builds 10 sequential boosting stages.

```python
n_estimators = 100
```

The model builds 100 sequential boosting stages.

```python
n_estimators = 500
```

The model builds 500 sequential boosting stages.

Remember:

These trees are not trained independently.

Each new stage uses information from the current model's remaining errors or gradients.

---

# 11. Understanding max_depth

Each boosting stage commonly uses a small Decision Tree.

The `max_depth` parameter controls the maximum depth of each individual tree.

Example:

```python
max_depth = 1
```

Each tree is a decision stump: a very shallow tree with at most one split level below the root.

```python
max_depth = 3
```

Each tree can learn more complicated relationships.

### Why use small trees?

Gradient Boosting combines many trees.

Each individual tree does not need to learn the entire relationship.

It only needs to contribute useful improvements to the existing model.

Small trees can help control complexity.

However, the best depth depends on the problem.

# 12. Training Gradient Boosting Regression in Python

Scikit-learn provides:

```python
GradientBoostingRegressor
```

Let's use your house-price dataset.

```python
from sklearn.ensemble import GradientBoostingRegressor

# Input features
X = [
    [1000, 2, 10],
    [1500, 3, 8],
    [2000, 3, 5],
    [2500, 4, 2],
    [3000, 4, 1]
]

# Actual prices
y = [20, 30, 40, 50, 60]

# Create model
model = GradientBoostingRegressor(
    n_estimators=100,
    learning_rate=0.1,
    max_depth=2,
    random_state=42
)

# Train model
model.fit(X, y)

# New house
new_house = [[1750, 3, 6]]

# Prediction
prediction = model.predict(new_house)

print(prediction)
```

### Understanding the code

**Step 1: Import the algorithm**

```python
from sklearn.ensemble import GradientBoostingRegressor
```

Imports Gradient Boosting Regression.

**Step 2: Prepare input features**

```python
X = [
    [1000, 2, 10],
    [1500, 3, 8],
    [2000, 3, 5],
    [2500, 4, 2],
    [3000, 4, 1]
]
```

Each row represents a house.

**Step 3: Prepare target values**

```python
y = [20, 30, 40, 50, 60]
```

These are the actual house prices.

**Step 4: Create the model**

```python
model = GradientBoostingRegressor(
    n_estimators=100,
    learning_rate=0.1,
    max_depth=2,
    random_state=42
)
```

The model is configured to use:

- 100 boosting stages.
- Learning rate of 0.1.
- Maximum tree depth of 2.

**Step 5: Train**

```python
model.fit(X, y)
```

The algorithm builds its trees sequentially.

**Step 6: Predict**

```python
prediction = model.predict([[1750, 3, 6]])
```

The model combines the contributions of all its boosting stages to produce one final prediction.

# 13. Important Gradient Boosting Hyperparameters

You should understand these parameters carefully.

## 13.1 n_estimators

Controls the number of boosting stages.

```python
n_estimators=100
```

Builds 100 sequential stages.

Increasing this value gives the model more opportunities to improve its predictions.

However, too many stages can lead to overfitting.

## 13.2 learning_rate

Controls the contribution of each new tree.

```python
learning_rate=0.1
```

A smaller learning rate generally requires more boosting stages.

## 13.3 max_depth

Controls the maximum depth of each individual tree.

```python
max_depth=3
```

Deeper trees can learn more complicated patterns but may overfit.

## 13.4 min_samples_split

Controls the minimum number of observations required in a node before a split can be considered.

```python
min_samples_split=10
```

## 13.5 min_samples_leaf

Controls the minimum number of observations required in a leaf.

```python
min_samples_leaf=5
```

## 13.6 subsample

Controls the fraction of training observations used to fit each boosting stage's tree.

Example:

```python
subsample=0.8
```

Uses a randomly selected 80% of training observations for each stage.

When the value is less than 1.0, the model uses stochastic gradient boosting.

This can help reduce variance, although it introduces additional randomness.

---

# 14. Understanding Overfitting in Gradient Boosting

Gradient Boosting can overfit.

Imagine you keep adding more and more trees.

At first, the model may improve because each tree corrects some remaining errors.

But eventually, additional trees may start learning noise and unnecessary details.

Example:

| Number of trees | Training MAE | Validation MAE |
|---:|---:|---:|
| 10 | 8.0 | 9.0 |
| 50 | 4.0 | 5.0 |
| 100 | 2.0 | 4.0 |
| 300 | 0.5 | 8.0 |

These numbers are illustrative.

The model improves on training data, but after a certain point, validation performance becomes worse.

This is overfitting.

### How to reduce overfitting

Try:

- Reducing `max_depth`.
- Increasing `min_samples_leaf`.
- Increasing `min_samples_split`.
- Reducing `learning_rate`.
- Adjusting `n_estimators`.
- Using `subsample` below 1.0.
- Using validation or cross-validation.

Do not assume a smaller learning rate automatically prevents overfitting. You must evaluate the complete combination of hyperparameters.

# 15. Gradient Boosting vs Random Forest

This is extremely important.

Both algorithms use multiple Decision Trees.

But they train them differently.

## Random Forest

Random Forest generally trains trees independently.

Each tree gets its own training sample and makes a prediction.

The predictions are averaged.

```text
              Dataset
                 |
        -------------------
        |        |        |
      Tree 1   Tree 2   Tree 3
        |        |        |
       40       45       42
        |        |        |
        -------------------
                 |
              Average
                 |
             Prediction
```

## Gradient Boosting

Gradient Boosting trains trees sequentially.

Each new tree attempts to improve the existing model.

```text
        Initial Prediction
                 |
              Tree 1
                 |
         Updated Prediction
                 |
              Tree 2
                 |
         Updated Prediction
                 |
              Tree 3
                 |
           Final Prediction
```

### Comparison

| Property | Random Forest | Gradient Boosting |
|---|---|---|
| Training | Trees are generally independent | Trees are trained sequentially |
| Main idea | Combine predictions | Improve existing predictions |
| Tree training | Uses different samples and feature choices | Each new tree learns from remaining gradients |
| Prediction | Usually averages tree predictions | Adds tree contributions |
| Learning rate | Not a standard main parameter | Important parameter |
| Training speed | Trees can be trained in parallel | Stages depend on previous stages |
| Overfitting | Can overfit | Can overfit |
| Main purpose | Reduce instability and variance | Build predictions through sequential improvements |

### Remember

Random Forest:

```text
Many independent trees → Average
```

Gradient Boosting:

```text
Tree → Correction → Tree → Correction
```

# 16. Feature Scaling in Gradient Boosting

Standard tree-based Gradient Boosting usually does not require feature scaling.

For example:

```text
Size = 2000
Bedrooms = 3
Age = 5
```

The algorithm uses feature-based split thresholds.

It does not calculate a weighted sum of the original features like ordinary linear regression.

Therefore, standard GradientBoostingRegressor generally works without StandardScaler or MinMaxScaler.

However, missing values and categorical features still need appropriate handling.

# 17. Understanding Loss Functions

Gradient Boosting can optimize different loss functions.

In scikit-learn's `GradientBoostingRegressor`, common options include:

## Squared Error

```python
loss="squared_error"
```

Uses squared-error loss.

It is a common starting point for regression.

## Absolute Error

```python
loss="absolute_error"
```

Uses absolute-error loss.

This is less sensitive to large residuals than squared-error loss.

## Huber Loss

```python
loss="huber"
```

Combines quadratic and linear loss behaviour.

You already learned about Huber Regression in the previous topic.

## Quantile Loss

```python
loss="quantile"
```

Allows the model to estimate a chosen conditional quantile.

For example:

```python
model = GradientBoostingRegressor(
    loss="quantile",
    alpha=0.9,
    random_state=42
)
```

This estimates the conditional 90th percentile.

Important:

`alpha` has a different meaning here than it does in Ridge or Lasso regression.

Always understand the parameter in the context of the specific estimator.

# 18. Evaluating Gradient Boosting Regression

Use the regression metrics you already learned.

```python
from sklearn.metrics import (
    mean_absolute_error,
    mean_squared_error,
    r2_score
)

import numpy as np

predictions = model.predict(X_test)

mae = mean_absolute_error(
    y_test,
    predictions
)

mse = mean_squared_error(
    y_test,
    predictions
)

rmse = np.sqrt(mse)

r2 = r2_score(
    y_test,
    predictions
)

print("MAE:", mae)
print("MSE:", mse)
print("RMSE:", rmse)
print("R2:", r2)
```

Remember:

- MAE measures average absolute error.
- MSE measures average squared error.
- RMSE is the square root of MSE.
- R² measures performance relative to a mean-prediction baseline.

Always compare Gradient Boosting with your other models using the same validation data and metrics.

For time-dependent data, use time-aware validation rather than randomly mixing past and future observations.

# 19. Advantages of Gradient Boosting

1. Can learn nonlinear relationships.
2. Can learn interactions between features.
3. Often performs well on structured tabular datasets.
4. Builds improvements sequentially.
5. Supports different loss functions.
6. Can model complicated patterns without manually writing equations.
7. Provides useful hyperparameters for controlling model complexity.

# 20. Limitations of Gradient Boosting

1. Training is sequential, so stages cannot generally be trained independently.
2. Can overfit if poorly configured.
3. Requires careful hyperparameter tuning.
4. Can be sensitive to noisy observations depending on the loss function.
5. Can require substantial computation with many trees.
6. More difficult to interpret than a simple Decision Tree.
7. Does not naturally extrapolate beyond the learned target range when using standard regression trees.

---

# 21. Practical Gradient Boosting Training Workflow

A practical workflow:

1. Prepare input features and target values.
2. Separate training, validation and test data.
3. Create a GradientBoostingRegressor.
4. Train using `fit()`.
5. Generate predictions using `predict()`.
6. Calculate MAE, MSE, RMSE and R².
7. Compare training and validation performance.
8. Tune `n_estimators`, `learning_rate` and `max_depth`.
9. Check for overfitting.
10. Compare with Linear Regression, Decision Tree and Random Forest.
11. Evaluate the final selected model on untouched test data.

Example:

```python
from sklearn.ensemble import GradientBoostingRegressor

from sklearn.metrics import (
    mean_absolute_error,
    mean_squared_error,
    r2_score
)

import numpy as np

model = GradientBoostingRegressor(
    n_estimators=200,
    learning_rate=0.05,
    max_depth=2,
    min_samples_split=5,
    min_samples_leaf=3,
    subsample=0.8,
    random_state=42
)

model.fit(X_train, y_train)

predictions = model.predict(X_test)

mae = mean_absolute_error(
    y_test,
    predictions
)

rmse = np.sqrt(
    mean_squared_error(
        y_test,
        predictions
    )
)

r2 = r2_score(
    y_test,
    predictions
)

print("MAE:", mae)
print("RMSE:", rmse)
print("R2:", r2)
```

These are example settings, not guaranteed optimal values.

Tune them using a validation set or cross-validation.

# 23. Final Understanding

Remember the complete process:

**Step 1:** The model creates an initial prediction.

**Step 2:** It calculates the remaining errors or negative gradients.

**Step 3:** It trains a Decision Tree to approximate those negative gradients.

**Step 4:** It adds the tree's contribution to the existing predictions.

**Step 5:** It calculates the new remaining errors.

**Step 6:** It trains another tree to improve the current model.

**Step 7:** It repeats the process for the configured number of stages.

The final prediction combines the initial prediction and the contributions of all the trees.

```text
             Initial Prediction
                     |
                     v
                  Tree 1
                     |
                     v
              Updated Prediction
                     |
                     v
                  Tree 2
                     |
                     v
              Updated Prediction
                     |
                     v
                  Tree 3
                     |
                     v
              Final Prediction
```

The biggest lesson:

A single Decision Tree makes one prediction.

Random Forest combines predictions from many independently trained trees.

Gradient Boosting builds trees sequentially, with each new tree attempting to improve the existing model.

**End of Gradient Boosting Regression.**
