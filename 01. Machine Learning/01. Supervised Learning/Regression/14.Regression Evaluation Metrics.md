
# Regression Evaluation Metrics — Complete Guide

# 1. Why Do We Need Evaluation Metrics?

After training a regression model, we need to check how well it predicts.

Training a model does not automatically mean that its predictions are accurate.

Evaluation metrics help us answer:

1. How far are predictions from actual values?
2. How large are prediction errors?
3. Does the model make some very large mistakes?
4. How much variation in the target does the model explain?
5. Does the model perform well on unseen data?
6. Which of two models performs better?

Important regression evaluation metrics:

1. MAE — Mean Absolute Error
2. MSE — Mean Squared Error
3. RMSE — Root Mean Squared Error
4. R² — R-squared
5. Adjusted R²
6. MAPE — Mean Absolute Percentage Error
7. Residual Analysis

---

# 2. Our House-Price Example

We will use the same actual prices throughout this document.

```python
actual = [20, 30, 40, 50]

predicted = [22, 28, 43, 47]
```

| House | Actual price | Predicted price |
|---|---:|---:|
| 1 | 20 | 22 |
| 2 | 30 | 28 |
| 3 | 40 | 43 |
| 4 | 50 | 47 |

None of the predictions exactly matches the actual price.

We need to measure how good or bad these predictions are.

# 3. Understanding Prediction Error

Prediction error is the difference between the actual value and predicted value.

```python
error = actual - predicted
```

| House | Actual | Predicted | Error |
|---|---:|---:|---:|
| 1 | 20 | 22 | -2 |
| 2 | 30 | 28 | 2 |
| 3 | 40 | 43 | -3 |
| 4 | 50 | 47 | 3 |

Python:

```python
actual = [20, 30, 40, 50]

predicted = [22, 28, 43, 47]

errors = []

for a, p in zip(actual, predicted):

    error = a - p

    errors.append(error)

print(errors)
```

Output:

```text
[-2, 2, -3, 3]
```

### Understanding positive and negative errors

- Positive error: Prediction is lower than the actual value.
- Negative error: Prediction is higher than the actual value.
- Zero error: Prediction exactly matches the actual value.

Some metrics use absolute or squared errors so positive and negative errors cannot cancel each other.

---

# PART 1 — MAE: MEAN ABSOLUTE ERROR

# 4. What Is MAE?

MAE stands for Mean Absolute Error.

It measures the average absolute difference between actual values and predicted values.

In simple words:

**MAE tells us how far the model's predictions are from the actual values on average.**

### Formula

\[
MAE=\frac{1}{n}\sum_{i=1}^{n}|y_i-\hat y_i|
\]

Where:

- n = Number of predictions.
- y = Actual value.
- ŷ = Predicted value.
- Absolute value = Removes the negative sign.

# 5. Understanding Absolute Value

Absolute value removes the negative sign.

| Number | Absolute value |
|---:|---:|
| 2 | 2 |
| -2 | 2 |
| 5 | 5 |
| -5 | 5 |
| 0 | 0 |

Our prediction errors:

```text
[-2, 2, -3, 3]
```

Absolute errors:

```text
[2, 2, 3, 3]
```

# 6. Calculate MAE Step by Step

Step 1: Calculate errors.

```text
[-2, 2, -3, 3]
```

Step 2: Remove negative signs.

```text
[2, 2, 3, 3]
```

Step 3: Add the absolute errors.

```text
2 + 2 + 3 + 3 = 10
```

Step 4: Divide by the number of examples.

```text
MAE = 10 / 4

MAE = 2.5
```

**Result: MAE = 2.5**

This means the average absolute prediction error is 2.5 units.

# 7. MAE Python Implementation

```python
actual = [20, 30, 40, 50]

predicted = [22, 28, 43, 47]

total_error = 0.0

for a, p in zip(actual, predicted):

    error = abs(a - p)

    total_error += error

mae = total_error / len(actual)

print("MAE:", mae)
```

Output:

```text
MAE: 2.5
```

Using NumPy:

```python
import numpy as np

actual = np.array([20, 30, 40, 50])

predicted = np.array([22, 28, 43, 47])

mae = np.mean(np.abs(actual - predicted))

print(mae)
```

Using Scikit-learn:

```python
from sklearn.metrics import mean_absolute_error

mae = mean_absolute_error(actual, predicted)

print(mae)
```

# 8. Advantages and Limitations of MAE

### Advantages

1. Easy to understand.
2. Uses the same unit as the target variable.
3. Does not allow positive and negative errors to cancel.
4. Less sensitive to large errors than MSE.
5. Useful when average absolute prediction error matters.

### Limitations

1. Does not penalize large errors as strongly as MSE.
2. Does not show the direction of prediction errors.
3. Does not explain how much variation the model captures.
4. Can hide individual very large errors behind an average.

### When Should We Use MAE?

Use MAE when you want a straightforward measurement of average prediction error.

For example:

If a house-price model has an MAE of ₹2 lakh, its predictions differ from actual prices by an average absolute amount of ₹2 lakh, assuming the target is measured in lakh rupees.

---

# PART 2 — MSE: MEAN SQUARED ERROR

# 9. What Is MSE?

MSE stands for Mean Squared Error.

It measures the average of squared prediction errors.

Unlike MAE, MSE squares each error.

This makes large errors contribute much more heavily to the final metric.

### Formula

\[
MSE=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y_i)^2
\]

Where:

- n = Number of examples.
- y = Actual value.
- ŷ = Predicted value.
- Squared error = Error multiplied by itself.

# 10. Why Do We Square Errors?

Suppose a model makes two errors:

```text
Error A = 2

Error B = 10
```

Their squared errors:

```text
2² = 4

10² = 100
```

The second error contributes 25 times as much squared error.

This is why MSE strongly penalizes large errors.

# 11. Calculate MSE Step by Step

Step 1: Calculate errors.

```text
[-2, 2, -3, 3]
```

Step 2: Square the errors.

```text
[-2]² = 4

[2]² = 4

[-3]² = 9

[3]² = 9
```

Squared errors:

```text
[4, 4, 9, 9]
```

Step 3: Add squared errors.

```text
4 + 4 + 9 + 9 = 26
```

Step 4: Divide by the number of examples.

```text
MSE = 26 / 4

MSE = 6.5
```

**Result: MSE = 6.5**

# 12. MSE Python Implementation

```python
actual = [20, 30, 40, 50]

predicted = [22, 28, 43, 47]

total_squared_error = 0.0

for a, p in zip(actual, predicted):

    error = a - p

    squared_error = error ** 2

    total_squared_error += squared_error

mse = total_squared_error / len(actual)

print("MSE:", mse)
```

Output:

```text
MSE: 6.5
```

Using NumPy:

```python
import numpy as np

mse = np.mean((actual - predicted) ** 2)

print(mse)
```

Using Scikit-learn:

```python
from sklearn.metrics import mean_squared_error

mse = mean_squared_error(actual, predicted)

print(mse)
```

# 13. Advantages and Limitations of MSE

### Advantages

1. Penalizes large errors strongly.
2. Useful for mathematical optimization.
3. Differentiable, making it convenient for Gradient Descent.
4. Commonly used to train regression models.
5. Gives more importance to large prediction mistakes.

### Limitations

1. Sensitive to outliers.
2. Its unit is the square of the target unit.
3. Less intuitive to interpret than MAE.
4. A few large errors can dominate the result.

### When Should We Use MSE?

Use MSE when large prediction errors should receive substantially greater penalties.

MSE is also a common training loss for Linear Regression and neural-network regression.

---

# PART 3 — RMSE: ROOT MEAN SQUARED ERROR

# 14. What Is RMSE?

RMSE stands for Root Mean Squared Error.

It is the square root of MSE.

\[
RMSE=\sqrt{MSE}
\]

Why take the square root?

MSE produces squared units.

For example:

If the target is measured in lakh rupees, MSE is measured in squared lakh rupees.

RMSE returns the result to the original target unit.

# 15. Calculate RMSE Step by Step

From our previous calculation:

```text
MSE = 6.5
```

Take the square root:

```text
RMSE = √6.5

RMSE ≈ 2.55
```

**Result: RMSE ≈ 2.55**

# 16. RMSE Python Implementation

```python
import math

mse = 6.5

rmse = math.sqrt(mse)

print("RMSE:", rmse)
```

Using NumPy:

```python
import numpy as np

rmse = np.sqrt(np.mean((actual - predicted) ** 2))

print(rmse)
```

Using Scikit-learn:

```python
from sklearn.metrics import root_mean_squared_error

rmse = root_mean_squared_error(actual, predicted)

print(rmse)
```

For older Scikit-learn versions:

```python
rmse = mean_squared_error(
    actual,
    predicted
) ** 0.5
```

# 17. Advantages and Limitations of RMSE

### Advantages

1. Uses the same unit as the target variable.
2. Penalizes large errors.
3. Useful for comparing regression models.
4. Commonly used in forecasting.
5. Easier to interpret than MSE.

### Limitations

1. Sensitive to outliers.
2. Large errors can dominate the result.
3. Does not show error direction.
4. Does not explain the proportion of variation captured by the model.

### When Should We Use RMSE?

Use RMSE when large prediction errors are especially undesirable and you want the result expressed in the original target unit.

# PART 4 — MAE VS MSE VS RMSE

# 18. Complete Comparison

Using our example:

| Metric | Result |
|---|---:|
| MAE | 2.5 |
| MSE | 6.5 |
| RMSE | 2.55 |

### Main Differences

| Property | MAE | MSE | RMSE |
|---|---|---|---|
| Operation | Absolute error | Squared error | Square root of MSE |
| Large-error penalty | Linear | Quadratic | Quadratic influence through MSE |
| Target unit | Original unit | Squared unit | Original unit |
| Outlier sensitivity | Lower | High | High |
| Easy interpretation | Yes | Less intuitive | Yes |
| Differentiability | Not differentiable at zero error | Differentiable | Generally differentiable except at zero RMSE |

# 19. Why Can MAE and RMSE Be Different?

Consider two models.

Model A errors:

```text
[2, 2, 2, 2]
```

Model B errors:

```text
[0, 0, 0, 8]
```

Both have the same MAE:

```text
Model A MAE = 2

Model B MAE = 2
```

But their RMSE values differ.

### Model A

```text
MSE = (4 + 4 + 4 + 4) / 4

MSE = 4

RMSE = 2
```

### Model B

```text
MSE = (0 + 0 + 0 + 64) / 4

MSE = 16

RMSE = 4
```

Model B has one much larger error.

RMSE reflects that more strongly.

This demonstrates why using more than one evaluation metric can be useful.

# PART 5 — R²: R-SQUARED

# 20. What Is R²?

R² is called the coefficient of determination.

It measures how much of the variation in the target values is explained by the regression model, relative to a baseline that predicts the target mean.

It is NOT an accuracy percentage.

### General Interpretation

- R² = 1: Perfect predictions on the evaluated data.
- R² = 0: The model performs like the mean-prediction baseline.
- R² below 0: The model performs worse than that baseline.

R² can be negative, particularly when the model performs poorly on evaluation data.

# 21. Understanding the Mean Baseline

Suppose actual house prices are:

```python
actual = [20, 30, 40, 50]
```

Calculate the average:

```text
Mean = (20 + 30 + 40 + 50) / 4

Mean = 35
```

A simple baseline model predicts 35 for every house.

```python
baseline_predictions = [35, 35, 35, 35]
```

R² compares the regression model against this baseline.

# 22. Understanding the Two Important Error Sums

R² uses two quantities.

### Total Sum of Squares (SST)

SST measures how much the actual values vary around their mean.

\[
SST=\sum_{i=1}^{n}(y_i-\bar y)^2
\]

Where:

- y = Actual value.
- ȳ = Mean of actual values.

### Residual Sum of Squares (SSE)

SSE measures the squared prediction errors remaining after using the model.

\[
SSE=\sum_{i=1}^{n}(y_i-\hat y_i)^2
\]

Where:

- y = Actual value.
- ŷ = Predicted value.

# 23. Calculate R² Step by Step

Actual values:

```text
[20, 30, 40, 50]
```

Predictions:

```text
[22, 28, 43, 47]
```

### Step 1: Calculate the actual mean.

```text
Mean = 35
```

### Step 2: Calculate SST.

```text
(20 - 35)² = 225

(30 - 35)² = 25

(40 - 35)² = 25

(50 - 35)² = 225
```

Add:

```text
SST = 225 + 25 + 25 + 225

SST = 500
```

### Step 3: Calculate SSE.

Our squared prediction errors were:

```text
[4, 4, 9, 9]
```

Therefore:

```text
SSE = 4 + 4 + 9 + 9

SSE = 26
```

### Step 4: Calculate R².

\[
R^2=1-\frac{SSE}{SST}
\]

Substitute:

\[
R^2=1-\frac{26}{500}
\]

\[
R^2=0.948
\]

**Result: R² = 0.948**

This means the model accounts for 94.8% of the variation in the evaluated target values relative to the mean baseline.

It does NOT mean that 94.8% of individual predictions are correct.

# 24. R² Python Implementation

```python
actual = [20, 30, 40, 50]

predicted = [22, 28, 43, 47]

actual_mean = sum(actual) / len(actual)

sse = 0.0

sst = 0.0

for a, p in zip(actual, predicted):

    sse += (a - p) ** 2

    sst += (a - actual_mean) ** 2

r2 = 1 - (sse / sst)

print("R2:", r2)
```

Output:

```text
R2: 0.948
```

Using Scikit-learn:

```python
from sklearn.metrics import r2_score

r2 = r2_score(actual, predicted)

print(r2)
```

# 25. Understanding Different R² Values

| R² | General interpretation |
|---:|---|
| 1.0 | Perfect fit |
| 0.9 | Strong performance relative to the mean baseline |
| 0.7 | Model explains 70% of target variation |
| 0.5 | Model explains 50% of target variation |
| 0.0 | Same squared-error performance as predicting the mean |
| -0.5 | Worse than the mean baseline |

These are mathematical interpretations, not universal quality standards.

A useful R² value depends on the problem, dataset and application.

# 26. Important R² Limitations

1. High R² does not guarantee accurate predictions in every situation.
2. High R² does not prove a causal relationship.
3. R² does not show the typical prediction error in the original unit.
4. R² can be negative on evaluation data.
5. Adding features to an ordinary least-squares model generally cannot decrease training R².
6. R² alone is insufficient for selecting a model.

Use MAE or RMSE alongside R².

# PART 6 — ADJUSTED R²

# 27. Why Do We Need Adjusted R²?

Ordinary R² generally stays the same or increases when additional predictors are added to an ordinary least-squares regression model fitted on the same data.

This can happen even when an added feature contributes little useful information.

Adjusted R² accounts for the number of predictors.

It penalizes unnecessary model complexity.

### Formula

\[
Adjusted\ R^2 =
1-(1-R^2)\frac{n-1}{n-p-1}
\]

Where:

- n = Number of observations.
- p = Number of independent input features.
- R² = Ordinary R-squared.

# 28. Calculate Adjusted R²

Suppose:

```text
R² = 0.948

n = 100

p = 3
```

Substitute:

\[
Adjusted\ R^2 =
1-(1-0.948)\frac{99}{96}
\]

\[
Adjusted\ R^2 \approx 0.9464
\]

Adjusted R² is slightly lower than ordinary R².

The adjustment accounts for the number of predictors.

# 29. Adjusted R² Python Implementation

```python
r2 = 0.948

n = 100

p = 3

adjusted_r2 = (
    1 - (1 - r2) * (n - 1) / (n - p - 1)
)

print(adjusted_r2)
```

### Important Limitations

- Adjusted R² is primarily used in regression settings where the predictor count and model fitting assumptions make the formula meaningful.
- It does not replace validation or test evaluation.
- It does not guarantee that selected features are useful.
- It should not be interpreted as a general metric for every machine-learning model.

# PART 7 — MAPE: MEAN ABSOLUTE PERCENTAGE ERROR

# 30. What Is MAPE?

MAPE stands for Mean Absolute Percentage Error.

It measures the average absolute prediction error as a percentage of the actual value.

### Formula

\[
MAPE=
\frac{100}{n}
\sum_{i=1}^{n}
\left|\frac{y_i-\hat y_i}{y_i}\right|
\]

Where:

- y = Actual value.
- ŷ = Predicted value.
- n = Number of examples.

# 31. Calculate MAPE

Actual:

```text
[20, 30, 40, 50]
```

Predicted:

```text
[22, 28, 43, 47]
```

Absolute errors:

```text
[2, 2, 3, 3]
```

Percentage errors:

```text
2 / 20 × 100 = 10%

2 / 30 × 100 ≈ 6.67%

3 / 40 × 100 = 7.5%

3 / 50 × 100 = 6%
```

Average:

```text
MAPE = (10 + 6.67 + 7.5 + 6) / 4

MAPE ≈ 7.54%
```

# 32. MAPE Python Implementation

```python
actual = [20, 30, 40, 50]

predicted = [22, 28, 43, 47]

total_percentage_error = 0.0

for a, p in zip(actual, predicted):

    percentage_error = abs((a - p) / a) * 100

    total_percentage_error += percentage_error

mape = total_percentage_error / len(actual)

print("MAPE:", mape)
```

Using Scikit-learn:

```python
from sklearn.metrics import mean_absolute_percentage_error

mape = mean_absolute_percentage_error(
    actual,
    predicted
)

print("MAPE:", mape * 100, "%")
```

Scikit-learn returns MAPE as a ratio, so multiply by 100 to express it as a percentage.

# 33. MAPE Limitations

1. It is undefined when an actual value is zero.
2. Very small actual values can produce extremely large percentage errors.
3. It can behave poorly with data containing zeros or values near zero.
4. Percentage errors can be misleading for some datasets.
5. It treats positive and negative errors symmetrically after taking absolute values.

For datasets containing zeros or values near zero, consider other metrics such as MAE or RMSE.

# PART 8 — RESIDUAL ANALYSIS

# 34. What Is a Residual?

A residual is the difference between an actual value and its predicted value.

\[
Residual=Actual-Predicted
\]

Example:

| Actual | Predicted | Residual |
|---:|---:|---:|
| 20 | 22 | -2 |
| 30 | 28 | 2 |
| 40 | 43 | -3 |
| 50 | 47 | 3 |

Residuals help us understand how the model makes mistakes.

# 35. Why Do We Study Residuals?

A single evaluation metric cannot explain every type of model problem.

For example, two models can have similar RMSE values but very different error patterns.

Residual analysis can help identify:

- Systematic prediction errors.
- Nonlinear relationships not captured by the model.
- Unequal error variance.
- Unusual observations.
- Patterns the model has failed to capture.

# 36. Residuals vs Prediction Errors

Residual and prediction error describe the difference between actual and predicted values.

In this document, both use:

```python
residual = actual - predicted
```

The term residual is commonly used when examining the errors left after fitting a model.

# 37. Residual Calculation in Python

```python
actual = [20, 30, 40, 50]

predicted = [22, 28, 43, 47]

residuals = []

for a, p in zip(actual, predicted):

    residual = a - p

    residuals.append(residual)

print(residuals)
```

Output:

```text
[-2, 2, -3, 3]
```

# 38. Residual Patterns

Residual analysis is useful because the average metric can hide problems.

### Pattern A: Randomly Scattered Residuals

If residuals are randomly scattered around zero, without a clear pattern, this can support the idea that the model has captured the main relationship.

### Pattern B: Curved Pattern

A curved residual pattern may indicate that the relationship is nonlinear and the current model has not captured it.

### Pattern C: Increasing Spread

If residuals become more spread out as predicted values increase, this may indicate unequal error variance.

This is also called heteroscedasticity.

### Pattern D: Unusual Large Residuals

Some observations may have much larger residuals than others.

These observations may deserve further investigation.

IMPORTANT:

Residual patterns are diagnostic clues. They do not automatically prove a particular problem.

# 39. Residual Plot

A residual plot places:

- Predicted values on the horizontal axis.
- Residuals on the vertical axis.

A horizontal reference line at zero helps identify whether residuals are scattered around zero.

Python example:

```python
import matplotlib.pyplot as plt

actual = [20, 30, 40, 50]

predicted = [22, 28, 43, 47]

residuals = []

for a, p in zip(actual, predicted):

    residuals.append(a - p)


plt.scatter(predicted, residuals)

plt.axhline(y=0)

plt.xlabel("Predicted Values")

plt.ylabel("Residuals")

plt.title("Residual Plot")

plt.show()
```

A useful residual plot should not show an obvious systematic pattern.

# PART 9 — TRAINING, VALIDATION AND TEST EVALUATION

# 40. Why Do We Need Separate Datasets?

A model should not be evaluated only on the data it used for training.

Training performance does not prove that the model will work well on unseen data.

Therefore, we divide the dataset into separate groups.

### Training Dataset

Used to learn model parameters.

### Validation Dataset

Used to compare models, select hyperparameters and monitor performance during development.

### Test Dataset

Used for final evaluation after model development decisions are complete.

# 41. Example Dataset Split

```text
Complete Dataset
       |
       +----> Training Data
       |
       +----> Validation Data
       |
       +----> Test Data
```

A common example:

| Dataset | Percentage |
|---|---:|
| Training | 70% |
| Validation | 15% |
| Test | 15% |

These percentages are examples, not mandatory rules.

The correct split depends on dataset size and the problem.

For time-series data, preserve chronological order rather than randomly mixing past and future observations.

# 42. Compare Training and Validation Metrics

Suppose:

| Metric | Training | Validation |
|---|---:|---:|
| MAE | 2.0 | 2.5 |
| RMSE | 2.5 | 3.0 |
| R² | 0.95 | 0.92 |

The model performs somewhat worse on validation data.

This is normal because the model was trained using the training dataset.

Now suppose:

| Metric | Training | Validation |
|---|---:|---:|
| MAE | 1.0 | 15.0 |
| RMSE | 1.5 | 20.0 |
| R² | 0.99 | 0.20 |

The large performance difference suggests that the model may not generalize well.

Possible reasons include overfitting or a difference between training and validation data distributions.

# PART 10 — EVALUATION USING SCIKIT-LEARN

# 43. Complete Evaluation Example

```python
from sklearn.metrics import (
    mean_absolute_error,
    mean_squared_error,
    r2_score,
    mean_absolute_percentage_error
)

import numpy as np


# Actual values

actual = np.array([20, 30, 40, 50])


# Model predictions

predicted = np.array([22, 28, 43, 47])


# MAE

mae = mean_absolute_error(
    actual,
    predicted
)


# MSE

mse = mean_squared_error(
    actual,
    predicted
)


# RMSE

rmse = np.sqrt(mse)


# R2

r2 = r2_score(
    actual,
    predicted
)


# MAPE

mape = mean_absolute_percentage_error(
    actual,
    predicted
) * 100


# Display results

print("MAE:", mae)

print("MSE:", mse)

print("RMSE:", rmse)

print("R2:", r2)

print("MAPE:", mape)
```

Expected results:

```text
MAE: 2.5

MSE: 6.5

RMSE: 2.5495

R2: 0.948

MAPE: 7.5417
```

# PART 11 — CHOOSING THE RIGHT METRIC

# 44. Which Metric Should We Use?

The correct metric depends on what matters in the application.

| Requirement | Useful metric |
|---|---|
| Average absolute prediction error | MAE |
| Strong penalty for large errors | MSE |
| Large-error penalty in original units | RMSE |
| Variation explained relative to mean baseline | R² |
| Compare fit while accounting for predictor count | Adjusted R² |
| Relative percentage error | MAPE |
| Diagnose error patterns | Residual analysis |

### Practical Recommendation

Do not rely on only one metric.

For a typical regression problem, a useful evaluation combination is:

- MAE.
- RMSE.
- R².
- Residual analysis.

This provides different perspectives on model performance.

# PART 12 — COMMON MISTAKES

# 45. Evaluation Mistakes to Avoid

### Mistake 1: Treating R² as Prediction Accuracy Percentage

R² = 0.90 does not mean that 90% of predictions are correct.

### Mistake 2: Using Only Training Data for Evaluation

Training performance does not prove generalization.

### Mistake 3: Ignoring Outliers

Large errors can significantly affect MSE and RMSE.

### Mistake 4: Using MAPE When Actual Values Contain Zero

MAPE is undefined for zero actual values.

### Mistake 5: Comparing Metrics With Different Target Units

Metrics should be interpreted in their proper units.

### Mistake 6: Assuming Lower Training Loss Always Means a Better Model

A model must also perform well on unseen data.

### Mistake 7: Ignoring Residual Patterns

A good average metric can hide systematic prediction problems.

### Mistake 8: Comparing Models on Different Test Datasets

Use the same evaluation data for a fair comparison.

### Mistake 9: Using the Test Dataset Repeatedly for Model Selection

Repeatedly tuning based on test results can cause information leakage into model development.

### Mistake 10: Assuming One Metric Works for Every Regression Problem

Metric selection should reflect the real-world cost of prediction errors.

| MAPE | Average absolute percentage error | Lower |
| Residual analysis | Error patterns and model assumptions | No systematic pattern |

# 47. Important Formulas

### MAE

\[
MAE=\frac{1}{n}\sum |y_i-\hat y_i|
\]

### MSE

\[
MSE=\frac{1}{n}\sum(y_i-\hat y_i)^2
\]

### RMSE

\[
RMSE=\sqrt{MSE}
\]

### R²

\[
R^2=1-\frac{SSE}{SST}
\]

### Adjusted R²

\[
Adjusted\ R^2 =
1-(1-R^2)\frac{n-1}{n-p-1}
\]

### MAPE

\[
MAPE=\frac{100}{n}\sum\left|\frac{y_i-\hat y_i}{y_i}\right|
\]

# 48. Final Understanding

Regression evaluation metrics help us understand different aspects of model performance.

- **MAE:** Measures average absolute prediction error.
- **MSE:** Penalizes large errors more strongly.
- **RMSE:** Expresses squared-error-based performance in the original target unit.
- **R²:** Measures performance relative to predicting the target mean.
- **Adjusted R²:** Accounts for the number of predictors in certain regression settings.
- **MAPE:** Expresses absolute errors as percentages.
- **Residual Analysis:** Helps identify patterns that summary metrics may hide.

A good regression evaluation process should use suitable metrics, separate evaluation data and careful error analysis.
