
# Regression Model Diagnostics

## 1. What Are Regression Model Diagnostics?

Imagine you trained a house-price prediction model.

Your model predicts prices, and you calculate evaluation metrics such as:

- MAE
- MSE
- RMSE
- R²

These metrics tell you how well your model predicts.

But they don't always explain *why* your model makes mistakes.

For example:

- Is the model missing an important relationship?
- Are its errors becoming larger for expensive houses?
- Are some unusual houses affecting the model?
- Are two input features providing almost the same information?
- Are errors connected to previous errors?

To investigate these questions, we use **regression model diagnostics**.

### Simple definition

Regression diagnostics are methods used to inspect a trained regression model, understand its errors, and identify problems with the model or its assumptions.

### Evaluation vs diagnostics

| Evaluation | Diagnostics |
|---|---|
| Measures prediction performance | Investigates model behaviour |
| MAE, MSE, RMSE, R² | Residual plots, VIF, Cook's distance |
| How accurate is the model? | What problems might the model have? |

Both are useful, but they answer different questions.

---

# 2. Understanding Residuals

Before learning diagnostics, you must understand residuals.

A residual is the difference between the actual value and the predicted value.

```python
residual = actual - predicted
```

Example:

| House | Actual price | Predicted price | Residual |
|---|---:|---:|---:|
| A | 20 | 22 | -2 |
| B | 30 | 28 | 2 |
| C | 40 | 43 | -3 |
| D | 50 | 47 | 3 |

For House A:

```python
actual = 20
predicted = 22

residual = actual - predicted

print(residual)
# -2
```

The model predicted 2 units too much.

For House B:

```python
actual = 30
predicted = 28

residual = actual - predicted

print(residual)
# 2
```

The model predicted 2 units too little.

### Understanding the residual sign

- Positive residual: prediction was too low.
- Negative residual: prediction was too high.
- Zero residual: prediction was exactly correct.

A residual is not the same as an absolute error.

```python
residual = actual - predicted

absolute_error = abs(actual - predicted)
```

Residuals preserve the direction of the error. Absolute errors do not.

# 3. Residuals vs Fitted Values Plot

This is one of the most important regression diagnostic plots.

First, understand two terms:

**Fitted value:** The prediction made by your trained model for an existing training example.

**Residual:** The difference between that example's actual value and its fitted value.

A residuals-versus-fitted plot displays:

- X-axis: predicted values.
- Y-axis: residuals.

### What should a good plot look like?

Ideally, the residuals should form a reasonably random cloud around the horizontal zero line.

There should not be an obvious pattern.

### Python example

```python
import matplotlib.pyplot as plt

actual = [20, 30, 40, 50]
predicted = [22, 28, 43, 47]

residuals = []

for a, p in zip(actual, predicted):
    residuals.append(a - p)

plt.scatter(predicted, residuals)

plt.axhline(y=0, linestyle="--")

plt.xlabel("Predicted Values")
plt.ylabel("Residuals")
plt.title("Residuals vs Fitted Values")

plt.show()
```

### Common patterns

**A. Random cloud**

 0 |-------------------
   |      .      .
 - |  .        .

   +------------------- Predicted

Interpretation:

- No obvious systematic pattern.
- This is generally a reassuring result.

It does not prove that the model is perfect.

**B. Curved pattern**

# 4. Linearity Assumption

Linear regression assumes that the expected target value can be represented as a linear combination of the model's coefficients and input features.

For example:

```python
prediction = (
    w1 * size +
    w2 * bedrooms +
    w3 * age +
    b
)
```

This is a multiple linear regression model.

### What does linearity mean?

It does not mean that every input feature must increase the house price.

It means the model represents the relationship using a linear combination of its coefficients and features.

For example, suppose the relationship between house size and price is curved:

- Small houses: price increases quickly with size.
- Medium houses: price increases moderately.
- Large houses: price increases slowly.

A simple linear model may struggle to represent this pattern.

### How do we investigate it?

Use:

- Residuals vs fitted plot.
- Residuals vs individual features.
- Scatter plots of features against the target.

### Possible solutions

- Add polynomial features.
- Add meaningful interaction features.
- Transform suitable variables.
- Try a nonlinear model.

Important: Linear regression can include features such as `size_squared`. It is still linear regression because it is linear in the coefficients.

# 5. Independence of Errors

Independence means that one observation's error should not systematically depend on another observation's error.

Imagine house prices collected over time.

| Month | Actual price | Prediction | Residual |
|---|---:|---:|---:|
| January | 20 | 19 | 1 |
| February | 22 | 21 | 1 |
| March | 24 | 23 | 1 |
| April | 26 | 25 | 1 |

The residuals are all positive and follow a sequence.

This may indicate that errors are related over time.

### Why does this matter?

Suppose a model consistently underestimates prices for several consecutive months.

Its errors may contain a time-related pattern that the model has not learned.

### Common example: Time-series data

Examples:

- Daily stock prices.
- Monthly sales.
- Hourly electricity demand.
- Daily cryptocurrency prices.

For time-series data, nearby observations can be related.

### How do we investigate it?

Plot residuals in chronological order.

```python
import matplotlib.pyplot as plt

residuals = [1, 2, 3, 2, 1, -1, -2, -3]

plt.plot(residuals)

plt.axhline(y=0, linestyle="--")

plt.xlabel("Observation Order")
plt.ylabel("Residual")
plt.title("Residuals Over Time")

plt.show()
```

Look for:

- Long runs of positive residuals.
- Long runs of negative residuals.
- Repeating patterns.
- Trends or cycles.

### Durbin-Watson statistic

The Durbin-Watson statistic is one method used to investigate first-order autocorrelation in residuals.

Its value generally ranges from 0 to 4.

| Value | General interpretation |
|---|---|
| Around 2 | Little evidence of first-order autocorrelation |
| Below 2 | Possible positive autocorrelation |
| Above 2 | Possible negative autocorrelation |

It is a diagnostic, not a complete test for every form of dependence.

# 6. Homoscedasticity and Heteroscedasticity

These two words describe how the spread of model errors behaves.

## 6.1 Homoscedasticity

Homoscedasticity means that the residuals have approximately constant variance across the range of fitted values or predictors.

In simple English:

The spread of errors should remain reasonably consistent.

Example:

| Predicted price | Typical error spread |
|---|---|
| 20 | Around ±2 |
| 30 | Around ±2 |
| 40 | Around ±2 |
| 50 | Around ±2 |

The error spread is approximately constant.

## 6.2 Heteroscedasticity

Heteroscedasticity means that the variance of errors changes across the range of fitted values or predictors.

Example:

| Predicted price | Typical error spread |
|---|---|
| 20 | Around ±1 |
| 30 | Around ±3 |
| 40 | Around ±6 |
| 50 | Around ±10 |

The errors become more spread out as predicted prices increase.

### Why can this happen?

Consider house prices.

Low-priced houses might have prices within a narrow range.

Expensive houses might have much more variation because of:

- Location.
- Construction quality.
- Facilities.
- Land value.
- Other factors.

A model may therefore have different error variance at different price levels.

### How do we detect it?

Use the residuals-versus-fitted plot.

- Approximately equal spread: consistent with homoscedasticity.
- Funnel-shaped spread: possible heteroscedasticity.

### Possible solutions

Depending on the problem:

- Transform the target, such as using a logarithm.
- Use weighted least squares.
- Use heteroscedasticity-robust standard errors when doing statistical inference.
- Improve the model's features.

Important:

Heteroscedasticity does not automatically mean that predictions are useless. It particularly affects the usual OLS standard-error and inference calculations.

# 7. Normality of Residuals

Normality means that the model's errors approximately follow a normal distribution.

A normal distribution has a familiar bell-shaped pattern.

For classical linear regression, residual normality is mainly relevant to certain statistical inference procedures, especially exact small-sample tests and confidence intervals under the usual assumptions.

### Important distinction

The assumption concerns the errors conditional on the predictors, not the requirement that the input features or target values themselves must be normally distributed.

Also, normal residuals are not required for ordinary least squares coefficients to be unbiased under the other relevant assumptions.

### How do we investigate it?

**A. Histogram**

```python
import matplotlib.pyplot as plt

plt.hist(residuals, bins=10)

plt.xlabel("Residual")
plt.ylabel("Frequency")
plt.title("Residual Distribution")

plt.show()
```

A roughly bell-shaped distribution can be reassuring.

**B. Q-Q plot**

A Q-Q plot compares the observed residual distribution with a theoretical normal distribution.

```python
import statsmodels.api as sm
import matplotlib.pyplot as plt

sm.qqplot(residuals, line="45")

plt.title("Residual Q-Q Plot")
plt.show()
```

Interpretation:

- Points roughly following the line: consistent with approximate normality.
- Strong systematic curves: possible departure from normality.
- Extreme points far from the line: possible heavy tails or unusual observations.

Do not decide everything from one plot or one statistical test.

# 8. Multicollinearity

Multicollinearity happens when two or more input features are strongly related to each other.

Imagine a house-price dataset:

| House | Size (sq ft) | Number of rooms |
|---|---:|---:|
| A | 1000 | 2 |
| B | 1500 | 3 |
| C | 2000 | 4 |
| D | 2500 | 5 |

Here, size and number of rooms move together.

They may provide overlapping information.

### Why can this be a problem?

Suppose a model uses:

```python
prediction = (
    w1 * size +
    w2 * bedrooms +
    b
)
```

If size and bedrooms are strongly related, it can become difficult to determine how much each feature independently contributes.

This can cause:

- Unstable coefficients.
- Large coefficient standard errors.
- Difficulty interpreting individual feature effects.
- Coefficients changing substantially when the training data changes.

Important:

Multicollinearity does not necessarily make predictions poor. A model can predict reasonably well while its individual coefficients are difficult to interpret.

### How do we investigate it?

**A. Correlation matrix**

```python
import pandas as pd

data = {
    "size": [1000, 1500, 2000, 2500],
    "bedrooms": [2, 3, 4, 5],
    "age": [10, 8, 5, 2]
}

df = pd.DataFrame(data)

print(df.corr())
```

This shows pairwise correlations.

However, pairwise correlation alone cannot detect every multicollinearity problem.

**B. Variance Inflation Factor (VIF)**

VIF measures how strongly one feature can be explained by the other input features in a linear regression setting.

General screening guide:

| VIF | Common interpretation |
|---|---|
| Around 1 | Little multicollinearity |
| Between 1 and 5 | Usually not severe |
| Above 5 | May deserve investigation |
| Above 10 | Often treated as serious |

These are rough guidelines, not strict laws.

### Python example

```python
import pandas as pd
import statsmodels.api as sm
from statsmodels.stats.outliers_influence import variance_inflation_factor

data = {
    "size": [1000, 1500, 2000, 2500, 3000],
    "bedrooms": [2, 3, 4, 5, 6],
    "age": [10, 8, 6, 4, 2]
}

df = pd.DataFrame(data)

X = sm.add_constant(df)

for i, column in enumerate(X.columns):
    if column == "const":
        continue

    vif = variance_inflation_factor(X.values, i)

    print(column, vif)
```

This is a small illustrative dataset. Because some features are perfectly related in this example, VIF values may become extremely large or infinite.

### Possible solutions

- Remove redundant features when justified.
- Combine related features.
- Collect more useful data.
- Use Ridge regression.
- Use other regularization methods when appropriate.

Do not automatically delete features just because their correlation is high.

# 9. Outliers, Leverage and Influential Observations

These three concepts are related, but they are not the same.

## 9.1 Outlier

An outlier is an observation that is unusual compared with the model's expected relationship.

In regression, we often investigate observations with unusually large residuals.

Example:

A house has an actual price of ₹50 lakh, but the model predicts ₹20 lakh.

The residual is:

```python
residual = 50 - 20

print(residual)
# 30
```

This observation has a large prediction error.

Possible reasons:

- Incorrect data.
- Missing features.
- A genuinely unusual house.
- Model limitations.

## 9.2 Leverage

Leverage measures how unusual an observation's input-feature values are compared with the rest of the training data.

Example:

Most houses in a dataset have sizes between 500 and 3000 square feet.

One house has a size of 20,000 square feet.

That observation may have high leverage because its input value is far away from the other observations.

High leverage does not automatically mean the observation is wrong.

## 9.3 Influential observation

An influential observation is one that substantially changes the fitted model when included or removed.

For example:

- Train a regression model with all houses.
- Train it again after temporarily removing one house.
- Compare the fitted coefficients.

If the model changes substantially, that observation may be influential.

### Remember the difference

| Concept | What is unusual? |
|---|---|
| Outlier | The target value relative to the model's prediction |
| High leverage | The input-feature values |
| Influential point | Its effect on the fitted model |

An observation can have:

- A large residual but low leverage.
- High leverage but a small residual.
- Both high leverage and a large residual.

High leverage alone does not prove that an observation is influential.

## 9.4 Cook's Distance

Cook's distance estimates how much the fitted regression model would change if a particular observation were removed.

A larger Cook's distance suggests greater influence.

Common screening guidelines include:

- Cook's distance greater than `4/n`.
- Cook's distance greater than `1`.

These are only rough investigation thresholds. They are not automatic rules for deleting observations.

### Python example

```python
import statsmodels.api as sm

X = sm.add_constant(df[["size", "bedrooms", "age"]])
y = [20, 30, 40, 50, 60]

model = sm.OLS(y, X).fit()

influence = model.get_influence()

cooks_distance = influence.cooks_distance[0]

print(cooks_distance)
```

This example assumes that `df` contains the five corresponding rows.

### What should you do with an unusual observation?

Investigate it.

Ask:

1. Is the data entry incorrect?
2. Is the measurement incorrect?
3. Is the house genuinely unusual?
4. Is an important feature missing?
5. Does the observation represent a real situation the model should learn?

Never automatically delete an observation just because it has a large residual or Cook's distance.

# 10. Using Statsmodels for Regression Diagnostics

So far, we have studied the concepts separately.

Now let's see how several diagnostics can be calculated using Python.

`statsmodels` is a Python library commonly used for statistical modelling and regression analysis.

It provides useful statistical summaries and diagnostic information.

### Example dataset

```python
import pandas as pd
import statsmodels.api as sm

data = {
    "size": [1000, 1500, 2000, 2500, 3000, 3500],
    "bedrooms": [2, 3, 3, 4, 4, 5],
    "age": [10, 8, 7, 5, 3, 2],
    "price": [20, 30, 35, 45, 50, 60]
}

df = pd.DataFrame(data)

X = df[["size", "bedrooms", "age"]]
y = df["price"]

# Add intercept
X = sm.add_constant(X)

# Train model
model = sm.OLS(y, X).fit()

# Display model summary
print(model.summary())
```

### What does the summary provide?

It includes:

- R-squared.
- Adjusted R-squared.
- Coefficients.
- Standard errors.
- t-statistics.
- p-values.
- Confidence intervals.
- Overall F-statistic.

These statistics help us understand the fitted regression model.

Remember: Statistical significance and predictive usefulness are different questions.

### Calculate residuals and fitted values

```python
predicted = model.fittedvalues

residuals = model.resid

print("Predicted:")
print(predicted)

print("Residuals:")
print(residuals)
```

### Residual plot

```python
import matplotlib.pyplot as plt

plt.scatter(predicted, residuals)

plt.axhline(y=0, linestyle="--")

plt.xlabel("Fitted Values")
plt.ylabel("Residuals")

plt.title("Residuals vs Fitted")

plt.show()
```

### Q-Q plot

```python
sm.qqplot(residuals, line="45")

plt.title("Normal Q-Q Plot")

plt.show()
```

### Cook's distance

```python
influence = model.get_influence()

cooks_distance = influence.cooks_distance[0]

print(cooks_distance)
```

These tools help you investigate the model. They do not automatically tell you which changes will improve it.

# 11. What to Do When Diagnostics Find a Problem

Finding a problem is only the first step.

You must investigate the cause and decide what to change.

| Problem | Possible action |
|---|---|
| Curved residual pattern | Add nonlinear features or try a nonlinear model |
| Funnel-shaped residual spread | Investigate target transformations, weighted regression or robust standard errors |
| Related errors over time | Investigate time dependence and use suitable time-series methods |
| Non-normal residuals | Investigate unusual observations, model specification and transformations |
| High multicollinearity | Investigate redundant features or regularization |
| Influential observation | Verify the data and understand why it has influence |
| Large residuals | Investigate missing features and unusual cases |

There is no single solution that works for every dataset.

Also, do not change a model simply to make every diagnostic plot look perfect. The correct response depends on whether your goal is prediction, statistical inference, or both.

# 12. Important Difference: Classical Regression vs Machine Learning

This distinction is important.

Some regression assumptions are especially important when using classical Ordinary Least Squares (OLS) to calculate statistical quantities such as:

- Coefficient standard errors.
- Confidence intervals.
- Hypothesis tests.
- p-values.

For predictive machine learning, the main question is often whether the model performs well on unseen data.

For example:

A model may have non-normal residuals but still make useful predictions.

A model may have multicollinearity but still predict accurately.

Therefore:

**Do not assume that violating one classical regression assumption automatically makes a model useless for prediction.**

Always connect the diagnostic result to your actual objective.

# 13. Complete Regression Diagnostics Workflow

A practical workflow:

1. Train the regression model.
2. Generate predictions.
3. Calculate residuals.
4. Plot residuals against fitted values.
5. Investigate linearity.
6. Investigate error independence, especially for time-series data.
7. Investigate constant error variance.
8. Examine the residual distribution when inference requires it.
9. Investigate multicollinearity.
10. Identify unusual observations, leverage and influential points.
11. Decide whether the findings require a model change.
12. Retrain the model if needed.
13. Evaluate it again on validation data.
14. Keep the test set separate for final evaluation.

# 15. Final Understanding

Regression diagnostics help answer questions that ordinary evaluation metrics cannot answer by themselves.

For example:

- MAE tells you the average absolute prediction error.
- RMSE tells you the error scale while penalizing large errors more strongly.
- R-squared measures performance relative to a mean-prediction baseline.
- Residual plots help reveal systematic error patterns.
- VIF helps investigate multicollinearity.
- Cook's distance helps identify potentially influential observations.

A good machine learning practitioner does not just train a model and look at its score.

They investigate how the model behaves, understand its weaknesses, make justified improvements, and evaluate it again.
