
# CatBoost Regression

## 1. What Is CatBoost?

CatBoost stands for **Categorical Boosting**.

It is a gradient-boosting algorithm developed by Yandex.

Like XGBoost and LightGBM, it builds multiple decision trees sequentially.

However, CatBoost is especially known for its techniques for handling categorical features.

### Simple definition

CatBoost is a gradient-boosting algorithm that builds decision trees sequentially and provides specialized techniques for handling categorical features.

It is commonly used for:

- House-price prediction.
- Customer behaviour prediction.
- Sales forecasting.
- Financial modelling.
- Fraud detection.
- Customer churn prediction.
- Risk prediction.

# 3. Why Are Categorical Features Difficult?

Imagine you have this column:

| Location |
|---|
| Chennai |
| Madurai |
| Coimbatore |
| Chennai |
| Madurai |

A machine learning algorithm cannot automatically treat these words as ordinary numerical measurements.

One simple approach is to convert categories into numbers.

For example:

| Location | Encoded value |
|---|---:|
| Chennai | 1 |
| Madurai | 2 |
| Coimbatore | 3 |

But there is a potential problem.

The numbers might look like they have a meaningful order:

```text
1 < 2 < 3
```

However:

```text
Chennai
Madurai
Coimbatore
```

do not have a natural numerical order.

Assigning arbitrary numbers can introduce misleading relationships in some algorithms.

Another approach is One-Hot Encoding.

For example:

| Location | Chennai | Madurai | Coimbatore |
|---|---:|---:|---:|
| Chennai | 1 | 0 | 0 |
| Madurai | 0 | 1 | 0 |
| Coimbatore | 0 | 0 | 1 |

This creates separate numerical columns.

It works, but datasets with many categories can produce a large number of columns.

CatBoost provides specialized categorical-feature handling to reduce the need for manually creating these encodings.

---

# 4. How CatBoost Handles Categorical Features

CatBoost can transform categorical information into numerical representations internally.

One important technique is called **Ordered Target Statistics**.

Let's understand the basic idea.

Imagine you have this dataset:

| Location | House price |
|---|---:|
| Chennai | 30 |
| Madurai | 40 |
| Chennai | 50 |
| Coimbatore | 60 |
| Madurai | 50 |
| Chennai | 70 |

The model wants to learn useful information about the locations.

For example, it may need to understand whether houses in a particular location tend to have higher or lower prices.

CatBoost uses statistical information about categories to help represent them.

However, there is an important problem.

If we calculate the average price for each location using every training observation, the representation can leak information from the observation whose target we are trying to predict.

This is called target leakage.

CatBoost uses ordering-based techniques to reduce this problem.

---

# 5. Understanding Ordered Target Statistics

Let's understand the basic intuition.

Imagine the following ordered training observations:

| Position | Location | Price |
|---|---|---:|
| 1 | Chennai | 30 |
| 2 | Madurai | 40 |
| 3 | Chennai | 50 |
| 4 | Coimbatore | 60 |
| 5 | Madurai | 50 |

Suppose we want to calculate a target-based statistic for the third observation.

That observation is:

```text
Location = Chennai
Price = 50
```

Instead of using all Chennai prices, CatBoost can use only earlier observations in the selected ordering.

Earlier Chennai observations:

```text
30
```

The current observation's target of 50 is not included in its own statistic.

This helps reduce direct target leakage.

### Important

This is a simplified illustration.

Actual CatBoost calculations use ordered permutations and prior information, including smoothing or prior terms.

It is not simply calculating the average of all earlier observations in one fixed dataset order.

### Why is this useful?

It helps CatBoost learn from categorical features while reducing target leakage caused by using an observation's own target during its encoding.

---

# 6. Understanding Ordered Boosting

CatBoost also introduces a technique called **Ordered Boosting**.

Remember the general Gradient Boosting process:

1. Make an initial prediction.
2. Calculate gradients or residual-related information.
3. Train a tree.
4. Update predictions.
5. Repeat.

There can be a prediction-shift problem when training calculations use information in ways that make training predictions behave differently from predictions on unseen observations.

CatBoost uses ordered boosting to help reduce this problem.

### Simple intuition

Imagine the model is learning from a training dataset.

If the model uses information from an observation in a way that indirectly benefits that same observation during training, its training behaviour may not represent how it behaves on genuinely unseen data.

Ordered Boosting uses permutation-based calculations to reduce this type of prediction shift.

### Remember

CatBoost has two important ideas:

1. Ordered Target Statistics: helps process categorical features.
2. Ordered Boosting: helps reduce prediction shift during boosting.

They are related to different parts of the learning process.

---

# 7. Understanding CatBoost's Symmetric Trees

Another important CatBoost feature is its default tree structure.

CatBoost commonly uses **symmetric trees**, also called oblivious trees.

In a symmetric tree, the same split condition is used at each node on a given depth level.

For example:

```text
                  Size <= 2000?
                   /         \
                 Yes          No
                 /             \
        Bedrooms <= 3?    Bedrooms <= 3?
            /    \             /    \
          Leaf   Leaf         Leaf   Leaf
```

Notice that the second level uses the same split condition on both sides.

This is the symmetric structure.

### Why is this useful?

Symmetric trees can provide:

- Efficient prediction.
- A regular tree structure.
- Fast evaluation.
- A consistent structure across each tree level.

Important:

CatBoost supports other tree-growth policies too, but symmetric trees are its standard default approach.

# 9. Training CatBoost Regression in Python

Let's use your house-price dataset.

This time, we'll include categorical features.

```python
import pandas as pd

from catboost import CatBoostRegressor

# Dataset
X = pd.DataFrame({
    "size": [1000, 1500, 2000, 2500, 3000],
    "bedrooms": [2, 3, 3, 4, 4],
    "age": [10, 8, 5, 2, 1],
    "location": [
        "Chennai",
        "Madurai",
        "Coimbatore",
        "Chennai",
        "Madurai"
    ],
    "property_type": [
        "Apartment",
        "Independent",
        "Apartment",
        "Villa",
        "Independent"
    ]
})

# Target
y = [30, 40, 50, 80, 60]

# Categorical feature names
cat_features = [
    "location",
    "property_type"
]

# Create model
model = CatBoostRegressor(
    iterations=200,
    learning_rate=0.05,
    depth=5,
    loss_function="RMSE",
    verbose=False,
    random_seed=42
)

# Train model
model.fit(
    X,
    y,
    cat_features=cat_features
)

# New house
new_house = pd.DataFrame({
    "size": [1750],
    "bedrooms": [3],
    "age": [6],
    "location": ["Chennai"],
    "property_type": ["Apartment"]
})

# Prediction
prediction = model.predict(new_house)

print(prediction)
```

### Understanding the code

**Step 1: Import CatBoost**


**Step 2: Create the dataset**


This dataset contains both numerical and categorical features.


This tells CatBoost which columns contain categorical values.

**Step 4: Create the model**

```python

    iterations=200,
    learning_rate=0.05,
    depth=5
)
```

Creates the CatBoost model.

**Step 5: Train the model**

```python

    X,

)
```

CatBoost trains the model and handles the specified categorical features using its categorical processing techniques.

# 10. Important CatBoost Hyperparameters

Let's understand the important settings.

## 10.1 iterations

Controls the number of boosting iterations.

```python
iterations=500
```

For the standard boosting setup, this corresponds to 500 boosting iterations.

More iterations provide more opportunities to improve the model, but can also increase training time and overfitting.

## 10.2 learning_rate

Controls the contribution of each boosting iteration.

```python
learning_rate=0.05
```

A smaller learning rate often requires more iterations.

## 10.3 depth

Controls the depth of the trees.

```python
depth=6
```

Deeper trees can learn more complicated relationships but may overfit.

## 10.4 l2_leaf_reg

Controls L2 regularization on leaf values.

```python
l2_leaf_reg=3
```

Increasing it generally discourages excessively large leaf values.

## 10.5 loss_function

Controls the training objective.

For standard regression:

```python
loss_function="RMSE"
```

Other options include:

```python
loss_function="MAE"
```

and:

```python
loss_function="Quantile:alpha=0.9"
```

The quantile example estimates the conditional 90th percentile.

## 10.6 random_seed

Controls randomness for reproducibility.

```python
random_seed=42
```

## 10.7 verbose

Controls training output.

```python
verbose=100
```

Prints progress periodically.

```python
verbose=False
```

Suppresses regular training output.

# 11. Understanding Early Stopping in CatBoost

Suppose you configure:

```python
iterations=1000
```

But validation performance stops improving after 300 iterations.

You can use early stopping.

Example:

```python
from catboost import CatBoostRegressor

model = CatBoostRegressor(
    iterations=1000,
    learning_rate=0.05,
    depth=6,
    loss_function="RMSE",
    random_seed=42,
    verbose=False
)

model.fit(
    X_train,
    y_train,
    eval_set=(X_val, y_val),
    early_stopping_rounds=50,
    verbose=False
)

print("Best iteration:", model.best_iteration_)
```

### Understanding the parameters

```python
iterations=1000
```

Allows up to 1000 boosting iterations.

```python
eval_set=(X_val, y_val)
```

Provides validation data.

```python
early_stopping_rounds=50
```

Stops training if the monitored validation metric does not improve for 50 consecutive rounds.

```python
model.best_iteration_
```

Returns the best iteration identified during training.

Important:

Do not use the final test dataset for early stopping.

Keep it untouched for final evaluation.

# 12. Understanding Feature Importance in CatBoost

CatBoost can estimate feature importance.

Example:

```python
import pandas as pd

importance = pd.DataFrame({
    "Feature": X.columns,
    "Importance": model.feature_importances_
})

importance = importance.sort_values(
    by="Importance",
    ascending=False
)

print(importance)
```

Illustrative output:

```text
Feature          Importance
size             45.0
location         25.0
property_type    15.0
bedrooms         10.0
age               5.0
```

These numbers are examples, not actual results.

CatBoost's default feature importance for ordinary regression is generally based on PredictionValuesChange.

It estimates how much predictions change when a feature's values are changed across the model's structure.

Important:

- Feature importance does not prove causation.
- Correlated features can affect interpretation.
- A high importance score does not automatically mean a feature is essential.

CatBoost also supports other feature-analysis methods, including SHAP values.

# 13. CatBoost vs XGBoost vs LightGBM

All three are advanced gradient-boosting algorithms.

| Property | XGBoost | LightGBM | CatBoost |
|---|---|---|---|
| Boosting | Sequential | Sequential | Sequential |
| Tree-based | Yes | Yes | Yes |
| Categorical handling | Supported with appropriate configuration | Supported with appropriate configuration | Specialized categorical processing |
| Tree growth | Commonly level-wise in its standard tree booster | Commonly leaf-wise | Symmetric by default |
| Histogram-based learning | Supported | Central design feature | Uses its own efficient tree-building approach |
| L1/L2 regularization | Yes | Yes | L2 leaf regularization |
| Missing numerical values | Supported by tree booster | Supported | Supported |
| Ordered boosting | No equivalent standard CatBoost method | No equivalent standard CatBoost method | Yes |

### Remember

XGBoost:

```text
Gradient Boosting
+
Second-order optimization
+
Regularization
```

LightGBM:

```text
Gradient Boosting
+
Histogram-based splitting
+
Leaf-wise growth
```

CatBoost:

```text
Gradient Boosting
+
Categorical feature processing
+
Ordered boosting
+
Symmetric trees by default
```

These are simplified summaries of their major design characteristics.

# 14. Does CatBoost Need Feature Scaling?

Generally, no.

CatBoost uses decision trees.

It does not normally require StandardScaler or MinMaxScaler for its standard tree-based regression models.

For example:

```text
Size = 2000
Bedrooms = 3
Age = 5
```

Different numerical scales are generally not a problem for tree-based split decisions.

However, you still need to handle:

- Incorrect values.
- Invalid data types.
- Missing or incorrectly represented categories.
- Data leakage.
- Poor-quality observations.

# 15. Does CatBoost Need One-Hot Encoding?

One of CatBoost's main advantages is that it can process categorical features internally.

You generally do not need to manually One-Hot Encode every categorical column before using CatBoost.

For example:

```python
cat_features = [
    "location",
    "property_type"
]
```

You can provide the categorical feature names when fitting a pandas DataFrame.

Important:

- Identify categorical columns correctly.
- Use supported input types.
- Keep the categorical representation consistent between training and prediction.
- Do not convert categories into arbitrary numerical values without understanding the consequences.

CatBoost may use different internal categorical processing methods depending on the feature, configuration and training data.

# 16. Understanding Overfitting in CatBoost

CatBoost can also overfit.

Imagine:

| Model | Training RMSE | Validation RMSE |
|---|---:|---:|
| Model A | 10 | 12 |
| Model B | 4 | 7 |
| Model C | 1 | 16 |

These numbers are illustrative.

Model C has extremely low training error but high validation error.

This indicates overfitting.

### How to reduce overfitting

Investigate:

- Reduce `depth`.
- Reduce `iterations`.
- Adjust `learning_rate`.
- Increase `l2_leaf_reg`.
- Use early stopping.
- Compare validation performance using cross-validation.

Do not change all hyperparameters simultaneously.

Change them systematically and compare the results.

1. Specialized handling of categorical features.
2. Supports numerical and categorical inputs.
3. Uses ordered techniques to reduce certain forms of target leakage and prediction shift.
4. Supports missing numerical values.
5. Can learn nonlinear relationships.

# 19. Practical CatBoost Training Workflow

A practical workflow:

1. Prepare input features and target values.
2. Identify categorical features.
3. Split into training, validation and test data.
4. Create a CatBoostRegressor.
5. Select a suitable loss function.
6. Train the model.
7. Monitor validation performance.
8. Use early stopping.
9. Calculate MAE, MSE, RMSE and R².
10. Tune hyperparameters.
11. Inspect feature importance.
12. Compare CatBoost with XGBoost and LightGBM.
13. Evaluate the final model on untouched test data.

Example:

```python
from catboost import CatBoostRegressor

from sklearn.metrics import (
    mean_absolute_error,
    mean_squared_error,
    r2_score
)

import numpy as np

cat_features = [
    "location",
    "property_type"
]

model = CatBoostRegressor(
    iterations=1000,
    learning_rate=0.03,
    depth=6,
    l2_leaf_reg=5,
    loss_function="RMSE",
    random_seed=42,
    verbose=False
)

model.fit(
    X_train,
    y_train,
    cat_features=cat_features,
    eval_set=(X_val, y_val),
    early_stopping_rounds=50,
    verbose=False
)

predictions = model.predict(X_test)

mae = mean_absolute_error(
    y_test,
    predictions
)

mse = mean_squared_error(
    y_test,
    predictions
)

rmse = np.sqrt(mse)

r2 = r2_score(
    y_test,
    predictions
)

print("MAE:", mae)
print("MSE:", mse)
print("RMSE:", rmse)
print("R2:", r2)
```

These are example settings, not guaranteed optimal values.

For time-dependent datasets, use chronological training, validation and test sets.

# 21. Final Understanding

Remember the main process.

**Step 1:** CatBoost receives the training dataset.

**Step 2:** It identifies numerical and categorical features.

**Step 3:** It processes categorical information using specialized techniques.

**Step 4:** It creates an initial prediction.

**Step 5:** It calculates gradients and builds a tree.

**Step 6:** It adds the tree's contribution to the existing predictions.

**Step 7:** It repeats the process for subsequent boosting iterations.

**Step 8:** It combines all tree contributions to generate the final prediction.

The biggest lesson:

CatBoost is a gradient-boosting algorithm with specialized categorical-feature handling and ordered techniques designed to reduce certain forms of prediction shift and target leakage.
