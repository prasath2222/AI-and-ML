
# Convergence in Gradient Descent

## 1. What is Convergence?

Convergence is the process in which Gradient Descent approaches a stable point where the loss is no longer decreasing significantly.

Remember the purpose of Gradient Descent:

1. Make predictions using the current weights.
2. Calculate the prediction errors.
3. Calculate the loss.
4. Calculate gradients.
5. Update weights and bias to reduce the loss.
6. Repeat this process.

During training, the model tries to find weights and bias that produce a low loss.

Initially, the loss may decrease significantly. As training continues, improvements may become smaller.

When the model approaches a stable point and further improvements become very small, we say that Gradient Descent is converging.

### Example

| Epoch | Loss |
|---|---:|
| 1 | 100 |
| 2 | 60 |
| 3 | 30 |
| 4 | 15 |
| 5 | 10 |
| 6 | 9.5 |
| 7 | 9.4 |
| 8 | 9.39 |
| 9 | 9.389 |

Notice:

- Initially, loss decreases quickly.
- Later, loss decreases more slowly.
- Eventually, improvements become extremely small.

This is an example of convergence.

**Important:** Convergence does not mean that loss must become zero. A model can converge while still making prediction errors.

---

## 2. Why Does Convergence Happen?

Gradient Descent updates weights using gradients.

The basic update rule is:

New Weight = Old Weight - (Learning Rate × Gradient)

The gradient tells us how the loss changes when a parameter changes.

Imagine a loss curve shaped like a valley.

When the model is far from the bottom:

- The slope may be steep.
- The gradient may be large.
- Weight updates may be relatively large.

When the model approaches the bottom:

- The slope becomes flatter.
- The gradient may become smaller.
- Weight updates may become smaller.

Eventually, the model may reach a point where its loss is no longer improving significantly.

This is why convergence occurs.

**Important:** A small gradient does not always prove that the model has reached a minimum. Flat regions and saddle points can also have small gradients.

---

## 3. Loss Curve During Convergence

A loss curve shows how the model's loss changes during training.

- X-axis: Epochs.
- Y-axis: Loss.

Example:

| Epoch | Loss |
|---|---:|
| 1 | 100 |
| 2 | 70 |
| 3 | 40 |
| 4 | 20 |
| 5 | 12 |
| 6 | 10 |
| 7 | 9.9 |
| 8 | 9.89 |

The loss curve initially decreases quickly and then becomes flatter.

A flattening loss curve can indicate that the model is approaching convergence.

There are three important observations:

1. Large loss reduction: Training is making significant progress.
2. Small loss reduction: Training is making less progress.
3. Almost no loss reduction: The model may have converged.

A flattening curve alone is not proof of successful training. We should also check whether the loss is sufficiently low and whether the model performs well on unseen data.

---

## 4. Local Minimum vs Global Minimum

To understand convergence, we need to understand two types of minimum.

### 4.1 Local Minimum

A local minimum is the lowest loss point within a nearby region of a loss curve.

Example:

| Weight | Loss |
|---|---:|
| 1 | 50 |
| 2 | 20 |
| 3 | 10 |
| 4 | 20 |
| 5 | 40 |

At weight 3, loss is 10.

The nearby weights have higher loss.

Therefore, weight 3 is a local minimum.

### 4.2 Global Minimum

A global minimum is the lowest loss point across the entire loss curve.

Example:

| Weight | Loss |
|---|---:|
| 3 | 10 |
| 4 | 20 |
| 5 | 40 |
| 6 | 15 |
| 7 | 3 |
| 8 | 15 |

Here:

- Weight 3 has loss 10.
- Weight 7 has loss 3.

Weight 3 is a local minimum.
Weight 7 is the global minimum.

**Remember:**

- Local minimum = Lowest in a nearby area.
- Global minimum = Lowest across the entire graph.

---

## 5. Can Gradient Descent Get Stuck at a Local Minimum?

Yes, in certain loss functions.

Gradient Descent uses the gradient at the current position to decide which direction to move.

It does not automatically know where the global minimum is.

Imagine a loss curve containing two valleys:

- The first valley has a local minimum with loss 10.
- The second valley has a global minimum with loss 3.

If Gradient Descent starts in the first valley, it may reach the local minimum.

At that point, there may be no downhill direction nearby.

Gradient Descent may stop making progress even though another valley has a lower loss.

This is called getting stuck at a local minimum.

### Important distinction

Ordinary linear regression with Mean Squared Error has a convex loss function with respect to its parameters.

For a convex loss function, every local minimum is also a global minimum.

However, complex non-convex models, including neural networks, can have more complicated loss landscapes.

---

## 6. Saddle Points

A saddle point is a point where the gradient can be zero, but the point is not a minimum or maximum.

Imagine a horse saddle.

At the center:

- In one direction, the surface curves upward.
- In another direction, the surface curves downward.

Therefore, the center is not a minimum.

### Why are saddle points important?

Gradient Descent uses gradients to decide how to update parameters.

At a saddle point, the gradient can be zero.

Using the update rule:

New Weight = Old Weight - (Learning Rate × Gradient)

If the gradient is zero:

New Weight = Old Weight

The parameter does not change at that exact point under ordinary gradient descent.

This can cause difficulty in making progress.

In real neural networks, very small gradients near saddle regions can also make training slow.

**Important:** A small gradient does not necessarily mean that the model has reached a minimum.

# Stopping Conditions in Gradient Descent

Convergence is often detected using stopping conditions.

A stopping condition tells the training process when it should stop updating the model.

There are several ways to detect convergence.

## 7. Loss-Based Stopping Condition

This method checks how much the loss improves between consecutive epochs.

Imagine these results:

| Epoch | Loss |
|---|---:|
| 1 | 100 |
| 2 | 50 |
| 3 | 20 |
| 4 | 19.995 |

The loss decreases from 20 to 19.995.

The improvement is:

20 - 19.995 = 0.005

The improvement is very small.

We can use this information to decide whether training should stop.

### What is a Threshold?

A threshold is a limit that we choose.

For example:

Threshold = 0.01

If the improvement becomes smaller than 0.01, we may consider stopping training.

### Python Example

```python
previous_loss = 20.0
current_loss = 19.995

threshold = 0.01

improvement = previous_loss - current_loss

if improvement < threshold:
    print("Convergence may have been reached")
```

Output:

```text
Convergence may have been reached
```

### Important

A single small improvement may happen temporarily.

Therefore, practical training often checks whether the loss improvement remains small over several consecutive epochs.

Also, this simple example assumes that loss is decreasing. For a more general implementation, compare the absolute difference or explicitly check whether the current loss improved.

---

## 8. Gradient-Based Stopping Condition

This method checks the size of the gradient.

Remember:

The gradient tells us how quickly the loss changes with respect to a parameter.

Imagine these gradient values:

| Epoch | Gradient |
|---|---:|
| 1 | 50 |
| 2 | 20 |
| 3 | 5 |
| 4 | 0.5 |
| 5 | 0.0001 |

The gradient becomes smaller during training.

A very small gradient can indicate that the loss curve is nearly flat in that direction.

We can define a gradient threshold.

Example:

```python
gradient = 0.0001

threshold = 0.001

if abs(gradient) < threshold:
    print("Gradient is very small")
```

Output:

```text
Gradient is very small
```

### Why use absolute value?

A gradient can be positive or negative.

For example:

- Gradient = 0.0001
- Gradient = -0.0001

Both have the same magnitude.

We use `abs()` to check how small the gradient is regardless of its sign.

### Multiple Parameters

In multiple linear regression, we have several parameters:

- w1
- w2
- w3
- b

Therefore, checking only one gradient is insufficient.

We can check the overall gradient magnitude using the gradient norm.

A gradient norm combines the sizes of all parameter gradients into one value.

If the overall gradient norm becomes sufficiently small, it can be used as a stopping condition.

**Important:** A small gradient does not guarantee a global minimum. It may also occur near a saddle point or a flat region.

---

## 9. Weight-Change-Based Stopping Condition

This method checks how much the model's parameters change during training.

Remember the weight update:

New Weight = Old Weight - (Learning Rate × Gradient)

Imagine these updates:

| Epoch | Old Weight | New Weight | Change |
|---|---:|---:|---:|
| 1 | 0.0 | 0.5 | 0.5 |
| 2 | 0.5 | 0.7 | 0.2 |
| 3 | 0.7 | 0.71 | 0.01 |
| 4 | 0.71 | 0.7101 | 0.0001 |

Notice that weight changes become smaller.

We can define a threshold.

Example:

```python
old_weight = 0.71
new_weight = 0.7101

threshold = 0.001

weight_change = abs(new_weight - old_weight)

if weight_change < threshold:
    print("Weight change is very small")
```

Output:

```text
Weight change is very small
```

This can indicate that training is approaching a stable point.

### Important

For multiple linear regression, we should consider changes in all weights and the bias, not only one weight.

Also, a small weight change does not automatically mean convergence. A very small learning rate can produce tiny updates even when the model is far from a good solution.

---

## 10. Maximum Epochs as a Stopping Condition

An epoch means one complete pass through the training dataset.

We can define the maximum number of epochs before training begins.

Example:

```python
max_epochs = 1000

for epoch in range(max_epochs):

    # Calculate predictions
    # Calculate loss
    # Calculate gradients
    # Update weights

    pass
```

Here, training can run for a maximum of 1,000 epochs.

Even if the model has not converged, training will stop when the maximum epoch count is reached.

### Why use maximum epochs?

1. Prevent training from running indefinitely.
2. Control training time.
3. Set a clear upper limit on training.

### Difference

Convergence-based stopping:

Stop because the model is no longer making meaningful progress.

Maximum-epoch stopping:

Stop because the allowed number of training epochs has been reached.

Maximum epochs are a safety limit, not proof of convergence.

---

## 11. Patience in Convergence Detection

One small loss improvement does not always mean training has converged.

Loss may fluctuate slightly between epochs.

Therefore, we can introduce a concept called patience.

Patience means how many consecutive epochs we allow without sufficient improvement before stopping.

Example:

```python
patience = 5
```

This means:

If the model does not achieve sufficient improvement for five consecutive epochs, training can stop.

### Example

Suppose:

| Epoch | Loss |
|---|---:|
| 1 | 100 |
| 2 | 50 |
| 3 | 30 |
| 4 | 29.9 |
| 5 | 29.89 |
| 6 | 29.88 |
| 7 | 29.87 |
| 8 | 29.86 |

If the improvement remains below our required threshold for the specified number of consecutive epochs, training can stop.

Patience helps avoid stopping because of one temporary small improvement.

# Problems During Gradient Descent

## 12. Convergence vs Divergence

These are opposite training behaviours.

### 12.1 Convergence

Convergence means the model is approaching a stable point with little further improvement.

Example:

| Epoch | Loss |
|---|---:|
| 1 | 100 |
| 2 | 60 |
| 3 | 30 |
| 4 | 15 |
| 5 | 10 |

Loss decreases during training.

### 12.2 Divergence

Divergence means training moves away from a useful solution, and loss may increase dramatically.

Example:

| Epoch | Loss |
|---|---:|
| 1 | 10 |
| 2 | 20 |
| 3 | 50 |
| 4 | 100 |
| 5 | 200 |

Loss increases instead of decreasing.

### Why can divergence happen?

One common reason is an excessively large learning rate.

The model takes updates that are too large and may repeatedly jump away from the minimum.

Other possible causes include numerical instability, problematic data, or an unsuitable optimization setup.

### Remember

- Convergence = Approaching a stable solution.
- Divergence = Moving away from a useful solution.

---

## 13. Oscillation During Gradient Descent

Oscillation means the loss repeatedly goes up and down during training.

Example:

| Epoch | Loss |
|---|---:|
| 1 | 10 |
| 2 | 5 |
| 3 | 8 |
| 4 | 4 |
| 5 | 7 |
| 6 | 3 |

Notice:

1. Loss decreases from 10 to 5.
2. Loss increases from 5 to 8.
3. Loss decreases from 8 to 4.
4. Loss increases from 4 to 7.

This repeated up-and-down movement is called oscillation.

### Why does oscillation happen?

One common reason is a learning rate that is too high.

Imagine trying to reach the bottom of a valley.

If each update is too large:

- The model jumps past the minimum.
- It moves to the other side.
- It jumps past the minimum again.

This can create oscillation.

### Remember

- Convergence: Approaching a stable minimum.
- Divergence: Moving away with increasing loss.
- Oscillation: Repeatedly moving up and down.

---

## 14. Difference Between Convergence, Divergence and Oscillation

| Behaviour | What happens to loss? |
|---|---|
| Convergence | Approaches a stable value |
| Divergence | Moves away and may increase dramatically |
| Oscillation | Repeatedly increases and decreases |

These behaviours help us understand whether Gradient Descent is training successfully.

# Monitoring Convergence in Practice

## 15. Training Loss and Loss Curves

During model training, we should record the loss after every epoch.

This allows us to observe the training process.

Example:

```python
loss_history = []

for epoch in range(1000):

    # Calculate predictions

    # Calculate loss

    # Calculate gradients

    # Update weights

    loss_history.append(loss)
```

The `loss_history` list stores the loss from each epoch.

We can later visualize these values using a graph.

### What should we look for?

1. Loss decreasing: The model is learning.
2. Loss becoming flatter: The model may be approaching convergence.
3. Loss increasing continuously: Possible divergence.
4. Loss repeatedly increasing and decreasing: Possible oscillation.
5. Loss staying unchanged: Training may have stopped improving, or there may be a problem with the training process.

---

## 16. Convergence vs Good Model Performance

These are not the same thing.

A model can converge but still perform poorly.

Example:

Imagine a house-price model that reaches a stable loss of 500.

The loss stops improving.

The model has converged, but its prediction errors may still be too large for the intended application.

Therefore:

- Convergence tells us about the training process.
- Model performance tells us how accurately the model predicts.

We must evaluate the model separately using appropriate metrics such as MAE, MSE, RMSE and R².

---

## 17. Convergence vs Overfitting

Convergence and overfitting are different concepts.

Convergence:

The training process approaches a stable solution.

Overfitting:

The model learns the training data too closely and performs poorly on unseen data.

A model can converge and still overfit.

For example:

| Epoch | Training Loss | Validation Loss |
|---|---:|---:|
| 1 | 100 | 110 |
| 2 | 60 | 70 |
| 3 | 30 | 40 |
| 4 | 15 | 30 |
| 5 | 8 | 35 |
| 6 | 5 | 45 |

Here:

- Training loss keeps decreasing.
- Validation loss starts increasing.

This suggests overfitting.

The training process may still be converging on the training data, but generalization is getting worse.

### Important

We should monitor both training loss and validation loss when evaluating model training.

# Practical Implementation

## 18. Implementing Convergence Detection in Python

Let's use our multiple linear regression model.

We have:

```python
size = [1000, 1500, 2000, 2500]
bedrooms = [2, 3, 3, 4]
age = [10, 8, 5, 2]

y = [20, 30, 40, 50]

n = 4

w1 = 0.0
w2 = 0.0
w3 = 0.0
b = 0.0

lr = 0.0000001
```

We can record the loss after each epoch and check whether the improvement becomes very small.

```python
max_epochs = 1000

threshold = 0.0001
patience = 5

previous_loss = None
small_improvement_count = 0

loss_history = []

for epoch in range(max_epochs):

    total_loss = 0.0

    sum_size_blame = 0.0
    sum_bedrooms_blame = 0.0
    sum_age_blame = 0.0
    sum_overall_blame = 0.0

    for Size, Bedrooms, Age, actual in zip(size, bedrooms, age, y):

        prediction = (
            w1 * Size +
            w2 * Bedrooms +
            w3 * Age +
            b
        )

        error = actual - prediction

        total_loss += error ** 2

        sum_size_blame += error * Size
        sum_bedrooms_blame += error * Bedrooms
        sum_age_blame += error * Age
        sum_overall_blame += error

    loss = total_loss / n

    loss_history.append(loss)

    # Calculate gradients after processing all samples

    size_grad = -(2 / n) * sum_size_blame
    bedrooms_grad = -(2 / n) * sum_bedrooms_blame
    age_grad = -(2 / n) * sum_age_blame
    b_gradient = -(2 / n) * sum_overall_blame

    # Update weights

    w1 = w1 - (lr * size_grad)
    w2 = w2 - (lr * bedrooms_grad)
    w3 = w3 - (lr * age_grad)
    b = b - (lr * b_gradient)

    # Check loss improvement

    if previous_loss is not None:

        improvement = previous_loss - loss

        if 0 <= improvement < threshold:

            small_improvement_count += 1

        else:

            small_improvement_count = 0

        if small_improvement_count >= patience:

            print("Convergence may have been reached")
            print("Stopped at epoch:", epoch + 1)

            break

    previous_loss = loss

print("Final weights:", w1, w2, w3)
print("Final bias:", b)
print("Final loss:", loss)
```

### What does this implementation do?

1. Trains the model.
2. Calculates predictions.
3. Calculates the Mean Squared Error.
4. Calculates gradients.
5. Updates weights and bias.
6. Stores the loss.
7. Checks whether loss improvement is smaller than the threshold.
8. Counts consecutive small improvements.
9. Stops when the patience limit is reached or the maximum epoch count is reached.

Note: This example uses a simple absolute loss-improvement threshold. In real applications, the threshold must be selected carefully, and feature scaling may be important because the inputs have different numerical ranges.

# Advanced Understanding

## 19. Convex and Non-Convex Loss Functions

Convergence behaviour also depends on the shape of the loss function.

### Convex Loss Function

A convex loss function has a bowl-like shape.

For a differentiable convex function, every local minimum is also a global minimum.

Ordinary linear regression using MSE has a convex objective with respect to its parameters.

This makes its optimization landscape simpler.

### Non-Convex Loss Function

A non-convex loss function can have:

- Multiple local minima.
- Saddle points.
- Flat regions.
- More complicated shapes.

Neural network training commonly involves non-convex loss functions.

This makes finding a good solution more challenging.

---

## 20. Why Feature Scaling Can Affect Convergence

Features can have very different numerical ranges.

For example:

| Feature | Value |
|---|---:|
| House size | 2000 |
| Bedrooms | 3 |
| Age | 10 |

The numerical ranges are very different.

This can affect gradient magnitudes and the shape of the optimization problem.

As a result, Gradient Descent may take inefficient steps or require a more carefully chosen learning rate.

Feature scaling brings numerical ranges to a more comparable scale.

Common techniques include:

- Standardization
- Min-Max Scaling

Feature scaling can make Gradient Descent converge more efficiently.
