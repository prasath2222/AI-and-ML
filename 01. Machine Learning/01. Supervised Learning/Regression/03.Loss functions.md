
# Dataset
actual = [10, 20, 30]
predicted = [8, 18, 35]
size = [1000, 1500, 2000]

n = len(actual)

# Choose loss function
loss_name = "MSE"

# Available:
# "MSE"
# "MAE"

total_loss = 0
sum_gradient_w = 0
sum_gradient_b = 0

for a, p, x in zip(actual, predicted, size):

    error = a - p

    if loss_name == "MSE":
        loss = error ** 2
        signal = error
        factor = -2 / n

    elif loss_name == "MAE":
        loss = abs(error)

        if error > 0:
            signal = 1
        elif error < 0:
            signal = -1
        else:
            signal = 0

        factor = -1 / n

    total_loss += loss
    sum_gradient_w += signal * x
    sum_gradient_b += signal

# Final loss
loss = total_loss / n

# Gradients
w_gradient = factor * sum_gradient_w
b_gradient = factor * sum_gradient_b

print("Loss:", loss)
print("Weight Gradient:", w_gradient)
print("Bias Gradient:", b_gradient)
    

    
## 1. Our dataset

We are predicting house prices using three input features:

```python
size = [1000, 1500, 2000, 2500]

age = [10, 8, 5, 2]

n = 4
y = [20, 30, 40, 50]
```

Our model:

```python
prediction = (
    w1 * Size +
    w2 * Bedrooms +
    w3 * Age +
    b
)
```

We want Gradient Descent to learn the best weights and bias by reducing prediction errors.

# 2. What is a Loss Function?

A loss function measures how wrong the model's predictions are.

For example:

| Actual price | Predicted price | Error |
|---:|---:|---:|
| 20 | 18 | 2 |
| 30 | 35 | -5 |
| 40 | 38 | 2 |
| 50 | 45 | 5 |

The loss function takes these errors and calculates a single value representing how wrong the model is.

**Gradient Descent uses the gradient of this loss function to update weights and bias.**

Different loss functions calculate errors differently. Therefore, their gradients are also different.

---

# 3. MSE — Mean Squared Error

## What does it do?

MSE squares every prediction error and calculates their average.

For example:

```python
error = actual - prediction

squared_error = error ** 2
```

If the error is 5:

```python
5 ** 2 = 25
```

If the error is -5:

```python
-5 ** 2 = 25
```

Both errors become positive.

## Why do we use MSE?

1. It penalizes large prediction errors heavily.
2. It provides smooth gradients for Gradient Descent.
3. It is commonly used in regression problems.
4. It works well when large prediction mistakes should be penalized strongly.

## MSE Gradient Calculation

With our error convention:

```python
error = actual - prediction
```

The gradient is:

```python
Size_grad = -(2/n) * Sum_size_blame
```

Where:

```python
Sum_size_blame += error * Size
```

The same process applies to bedrooms, age, and bias.

### Why 2/n?

- `2` comes from differentiating the squared error.
- `n` comes from averaging across training samples.
- The negative sign comes from using `actual - prediction` as our error.

## When should we use MSE?

Use MSE when:
- Large prediction mistakes are especially costly.
- Your dataset does not contain many extreme outliers.
- You want a standard loss function for regression.

---

# 4. MAE — Mean Absolute Error

## What does it do?

MAE takes the absolute value of every prediction error and calculates their average.

```python
absolute_error = abs(error)
```

Examples:

```python
abs(5)   = 5
abs(-5)  = 5
```

Unlike MSE, it does not square the error.

## Why do we use MAE?

1. It is less sensitive to extreme errors than MSE.
2. It measures average prediction error directly.
3. It is easier to interpret in the original target units.

## MAE Gradient Calculation

For MAE, differentiating the absolute error gives its direction:

| Error | Sign |
|---:|---:|
| Positive | +1 |
| Negative | -1 |

The gradient becomes:

```python
Size_grad = -(1/n) * Sum_size_direction
```

Instead of accumulating the actual error multiplied by the feature:

```python
Sum_size_blame += error * Size
```

We accumulate the sign of the error multiplied by the feature:

```python
if error > 0:
    direction = 1
elif error < 0:
    direction = -1
else:
    direction = 0

Sum_size_direction += direction * Size
```

The same process applies to bedrooms, age, and bias.

**Important:** MAE is not as smooth as MSE. At zero error, its derivative is not uniquely defined. In practice, we use a subgradient of zero there.

## When should we use MAE?

Use MAE when:
- Your dataset contains extreme outliers.
- You don't want large errors to dominate the loss as strongly.
- You care about average absolute prediction error.

---

# 5. RMSE — Root Mean Squared Error

## What does it do?

RMSE takes the square root of MSE.

Its calculation:

```python
RMSE = (Sum_squared_error / n) ** 0.5
```

Example:

```python
MSE = 25

RMSE = 25 ** 0.5

# RMSE = 5
```

## Why do we use RMSE?

1. It penalizes large errors more than MAE.
2. It is expressed in the same units as the target.
3. It is easier to interpret than MSE when the target has meaningful units.

## RMSE Gradient Calculation

RMSE is not exactly the same as MSE.

Its gradient is:

```python
Size_grad = -(1 / (n * RMSE)) * Sum_size_blame
```

Where:

```python
Sum_size_blame += error * Size
```

Notice the difference:

| MSE | RMSE |
|---|---|
| `-(2/n)` | `-(1/(n * RMSE))` |
| Uses squared error as its loss | Uses square root of MSE |
| Gradient contains the factor 2 | Gradient contains the RMSE denominator |

If RMSE becomes zero, this expression needs special handling because division by zero is not possible.

## When should we use RMSE?

- When you want to measure errors in the original target units.
- When large errors should receive more attention.
- It is commonly used to evaluate regression models.

**Practical note:** RMSE and MSE have the same optimal predictions because square root is an increasing function. MSE is generally simpler to optimize directly.

---

# 6. Huber Loss

## What does it do?

Huber Loss combines the behavior of MSE and MAE.

- For small errors, it behaves like MSE.
- For large errors, it behaves like MAE.

It uses a threshold called `delta`.

For example, if:

```python
delta = 1
```

Then:

| Absolute error | Behavior |
|---:|---|
| 0.2 | MSE-like |
| 0.5 | MSE-like |
| 1.0 | MSE-like |
| 3.0 | MAE-like |
| 10.0 | MAE-like |

## Why do we use Huber Loss?

1. It is smoother around zero than MAE.
2. It is less sensitive to extreme errors than MSE.
3. It can be useful when your dataset contains outliers but you still want smooth optimization.

## Huber Gradient Calculation

First, calculate a modified error signal:

```python
if abs(error) <= delta:
    signal = error
else:
    if error > 0:
        signal = delta
    else:
        signal = -delta
```

Then:

```python
Size_grad = -(1/n) * Sum_size_huber
```

Where:

```python
Sum_size_huber += signal * Size
```

The same process applies to bedrooms, age, and bias.

## When should we use Huber Loss?

- When your dataset has some extreme outliers.
- When MSE is too sensitive to those outliers.
- When MAE's less-smooth optimization behavior is undesirable.

# 7. Complete Python Training Code — All Four Loss Functions

We can use the same dataset, weights, bias, and Gradient Descent structure.

We only change the selected loss function.

```python
# Dataset
size = [1000, 1500, 2000, 2500]
bedrooms = [2, 3, 3, 4]
age = [10, 8, 5, 2]

n = 4
y = [20, 30, 40, 50]


# Choose loss function
loss_name = "MSE"

# Available:
# "MSE"
# "MAE"
# "RMSE"
# "HUBER"

delta = 1.0


# Weights
w1 = 0.0
w2 = 0.0
w3 = 0.0
b = 0.0

lr = 0.0000001


for epoch in range(1000):

    # Reset gradient sums
    Sum_size_blame = 0.0
    Sum_bedrooms_blame = 0.0
    Sum_age_blame = 0.0
    Sum_overall_blame = 0.0

    Sum_squared_error = 0.0
    Sum_absolute_error = 0.0
    Sum_huber_loss = 0.0

    for Size, Bedrooms, Age, actual in zip(
        size, bedrooms, age, y
    ):

        # Prediction
        prediction = (
            w1 * Size +
            w2 * Bedrooms +
            w3 * Age +
            b
        )

        error = actual - prediction

        # Calculate squared and absolute errors
        Sum_squared_error += error ** 2
        Sum_absolute_error += abs(error)


        # Select gradient signal
        if loss_name == "MSE":

            signal = error

        elif loss_name == "MAE":

            if error > 0:
                signal = 1
            elif error < 0:
                signal = -1
            else:
                signal = 0

        elif loss_name == "RMSE":

            signal = error

        elif loss_name == "HUBER":

            if abs(error) <= delta:
                signal = error
            elif error > 0:
                signal = delta
            else:
                signal = -delta

            # Huber loss value
            if abs(error) <= delta:
                Sum_huber_loss += 0.5 * error ** 2
            else:
                Sum_huber_loss += (
                    delta * (abs(error) - 0.5 * delta)
                )


        # Accumulate gradients
        Sum_size_blame += signal * Size
        Sum_bedrooms_blame += signal * Bedrooms
        Sum_age_blame += signal * Age
        Sum_overall_blame += signal


    # Calculate selected loss and gradient factor
    if loss_name == "MSE":

        training_loss = Sum_squared_error / n
        gradient_factor = -2 / n

    elif loss_name == "MAE":

        training_loss = Sum_absolute_error / n
        gradient_factor = -1 / n

    elif loss_name == "RMSE":

        training_loss = (Sum_squared_error / n) ** 0.5

        if training_loss > 0:
            gradient_factor = -1 / (n * training_loss)
        else:
            gradient_factor = 0

    elif loss_name == "HUBER":

        training_loss = Sum_huber_loss / n
        gradient_factor = -1 / n


    # Calculate gradients
    Size_grad = gradient_factor * Sum_size_blame
    Bedrooms_grad = gradient_factor * Sum_bedrooms_blame
    Age_grad = gradient_factor * Sum_age_blame
    B_gradient = gradient_factor * Sum_overall_blame


    # Update weights
    w1 = w1 - (lr * Size_grad)
    w2 = w2 - (lr * Bedrooms_grad)
    w3 = w3 - (lr * Age_grad)
    b = b - (lr * B_gradient)


    # Training monitor
    if (epoch + 1) % 100 == 0:

        print(
            f"Epoch: {epoch + 1} | "
            f"{loss_name}: {training_loss:.6f}"
        )


# Final weights
print("\nFinal Weights")

print(f"w1: {w1:.6f}")
print(f"w2: {w2:.6f}")
print(f"w3: {w3:.6f}")
print(f"b:  {b:.6f}")


# New house prediction
new_size = 5000
new_bedrooms = 2
new_age = 20

prediction = (
    w1 * new_size +
    w2 * new_bedrooms +
    w3 * new_age +
    b
)

print("\nNew House Prediction:", prediction)
```

**Important:** Change `loss_name` to select another training objective. The code recalculates the corresponding loss and gradient. The learning rate may need adjustment when you change loss functions.

# 8. Comparison — Which One Should We Choose?

| Loss | Gradient factor in this code | Main characteristic |
|---|---|---|
| MSE | `-2/n` | Strongly penalizes large errors |
| MAE | `-1/n` | Uses error direction, less sensitive to outliers |
| RMSE | `-1/(n * RMSE)` | MSE-like optimization, original target units |
| Huber | `-1/n` | MSE for small errors, MAE-like for large errors |

The gradient factor alone does not define the gradient. The value being accumulated also changes.

For example:

```python
# MSE
signal = error

# MAE
signal = sign(error)

# RMSE
signal = error

# Huber
signal = clipped_error
```

# 9. What Should You Learn First for AI/ML Jobs?

My recommended learning order:

1. **MSE:** Understand it deeply because it is a standard regression loss and a useful starting point for Gradient Descent.
2. **MAE:** Understand how absolute errors change the training objective and gradient.
3. **RMSE:** Understand its relationship with MSE and why it is commonly used for evaluation.
4. **Huber:** Understand how it balances MSE and MAE.

In real projects, you do not choose a loss function randomly. You consider:

- What kind of prediction errors matter?
- Are there extreme outliers?
- How should large mistakes be penalized?
- Which loss gives better validation performance?

**Final takeaway:** A loss function defines what the model considers a mistake. Its gradient tells Gradient Descent how to change the weights to reduce that mistake.
